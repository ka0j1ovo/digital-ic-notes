# 数字集成电路设计 · 精讲讲义

把课堂 PPT（第 3—12 章）逐页整理成**单文件 HTML 讲义**：每章一个 `.html`，样式、目录、插图全部内嵌，双击即可离线阅读，也可以直接打印/导出 PDF。

## 章节目录

| 章节 | 内容 | 文件 |
|---|---|---|
| 第 3 章 | MOS 器件：结构、阈值、I–V、电容、非理想效应 | `数字集成电路设计_第3章_MOS器件_精讲讲义.html` |
| 第 4 章 | 互连线：电容、电阻、RC 延迟、中继器、串扰 | `数字集成电路设计_第4章_互连线_精讲讲义.html` |
| 第 5 章 | CMOS 反相器：VTC、噪声容限、延迟、功耗、尺寸设计 | `数字集成电路设计_第5章_CMOS反相器_精讲讲义.html` |
| 第 6 章 | 组合逻辑门：互补 CMOS、有比、动态、传输门 | `数字集成电路设计_第6章_组合逻辑门_精讲讲义.html` |
| 第 7 章 | 时序逻辑门：锁存器、触发器、建立/保持、时钟 | `数字集成电路设计_第7章_时序逻辑门_精讲讲义.html` |

| 第 11 章 | 算术运算单元：全加器、超前进位、乘法器、移位器 | `数字集成电路设计_第11章_算术运算单元_精讲讲义.html` |
| 第 12 章 | 存储器：SRAM、DRAM、ROM、灵敏放大器、ECC | `数字集成电路设计_第12章_存储器_精讲讲义.html` |

从 `index.html` 进入有卡片式目录。

## 阅读工具

第 3 章的页面右下角带两个工具（其余章节可按需加）：

- **🔍 搜索**：`Ctrl+F` 或点按钮，输入关键字自动跳转，回车/“下一项”逐个跳，计数显示 `n / 总数`。
- **✏️ 标注**：选择“高亮”后在正文里拖动（手机长按）选中文字即变黄；选择“擦除”后选中已标注文字即可清除；标注保存在浏览器本地（localStorage），刷新不丢。

## 本地查看

直接双击 `index.html` 即可。若要模拟线上环境：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/
```
