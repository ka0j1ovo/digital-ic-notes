这一章的主题只有一个：把“进位”这个串行依赖压缩到最短。加法器的快慢几乎完全由进位决定，乘法器、比较器、地址计算全都建立在它之上。

0 导学：数据通路的地位

PPT 第 2、3 页把数字系统分成四块：存储器、数据通路（datapath）、控制、接口。数据通路就是“按位做运算”的那部分电路：加法器、乘法器、移位器、比较器。它的特点是规则、重复、位宽大，所以设计时最关心“关键路径上的进位/进位链”。

本章的逻辑链条非常清晰：

全加器 → 进位链（串行→并行）→ 超前进位树（对数）→ 乘法器 → 移位器

每一级都是为了解决上一级的“串行太慢”问题。

1 全加器：1 位加法的最小单元

1.1 布尔式

S = A ⊕ B ⊕ Ci = Ā B̄ Ci + Ā B C̄i + A B̄ C̄i + A B Ci(11-1)
Co = A B + B Ci + A Ci = AB + (A + B)Ci(11-2)

记住第二种写法 C_o = AB + (A+B)C_i：它把“产生进位（AB）”和“传递进位（(A+B)C_i）”分开了——这正是所有快速进位结构的出发点。

1.2 用互补静态 CMOS 实现：28 个管子

直接用 §1.1 的式子做静态 CMOS，需要 28 个晶体管（PPT 第 5 页）。原因是 C_o 和 S 都是多输入函数，每个都要一套 PUN/PDN，还要反相器。

图 1-1　行波进位加法器：进位一级一级串过去，关键路径长度 ∝ N（PPT 第 6 页）

它还揭示了一个重要事实：C_o 的负载很重——2 个扩散电容 + 6 个栅电容 + 连线电容。因为 C_o 要驱动下一级的三个输入（A、B、Ci），所以加法器的关键路径天然就是进位路径。

1.3 镜像加法器：24 管，利用“全反相等价”

PPT 第 8、9 页给了一个漂亮的性质：全加器所有输入输出同时取反，功能不变：

S̄(A,B,Ci) = S(Ā,B̄,C̄i), C̄o(A,B,Ci) = Co(Ā,B̄,C̄i)(11-3)

利用这一点，可以让相邻的全加器交替使用正相/反相，于是进位链上不需要额外的反相器——这既省管子又省延迟。镜像加法器（mirror adder）就是把这个思想做到极致：PDN 与 PUN 完全对称，只有 24 个晶体管，而且进位路径上最多只有 2 个管子串联。

设计要点（PPT 第 15 页）：让 C_o 节点的电容最小（扩散电容 4、栅电容 2、下一级栅电容 6），把连 C_i 的管子放在靠近输出处，求和电路全部用最小尺寸。

1.4 传输门加法器：用“选择”代替“计算”

PPT 第 17、22 页用传输门实现全加器：先用几个门生成 G、P、D，再用传输门“选择”进位：

G = AB（generate）, D = ¬(A+B)（delete）, P = A ⊕ B（propagate）(11-4)
Co = G + P Ci, S = P ⊕ Ci(11-5)

这样进位就变成了“如果 G 则输出 1，如果 D 则输出 0，否则跟随 Ci”——用传输门做这个三选一，只要 24 个管子，而且 S 与 C_o 两条路径对称。

2 进位链：从串行到并行

2.1 行波进位：最简单，也最慢

把 N 个全加器串起来，进位一级一级传：

tadder = (N − 1)·tcarry + tsum → t = O(N)(11-6)

注意那个 (N−1)：最后一位的结果要等进位一路传过去。32 位加法器就要串 31 级，这就是“行波进位加法器”（ripple-carry adder）慢的原因。

2.2 进位状态：G / P / D

PPT 第 16 页用真值表定义了三种进位状态，这是整个快速进位理论的语言：

2.3 曼彻斯特进位链：一级传输门

Manchester 进位链（PPT 第 20、21 页）用动态逻辑实现：先预充，再用一串传输门把进位“拉”过去，G 直接把节点拉低。它的优点是进位延迟只有一级传输门 + 一个反相器；缺点是需要时钟、而且进位链太长时传输门的串联电阻会拖慢速度。

3 超前进位与树形结构：把延时压到 log N

3.1 超前进位（CLA）的展开

把 C_o = G + P·C_i 递归展开（PPT 第 33 页）：

Co,0 = G0 + P0Ci,0(11-7)
Co,1 = G1 + P1G0 + P1P0Ci,0(11-8)
Co,2 = G2 + P2G1 + P2P1G0 + P2P1P0Ci,0(11-9)
Co,3 = G3 + P3G2 + P3P2G1 + P3P2P1G0 + P3P2P1P0Ci,0(11-10)

这四行说明：每一位的进位都可以用“输入 + 初始进位”直接算出来，不必等前一级。 代价是门数随位宽爆炸（第 n 位要 n+1 个乘积项），所以不能对 32 位直接展开。

3.2 点运算：树形结构的“积木”

为了既保持并行、又不让门数爆炸，把进位的组合抽象成点运算（dot operation）：

(G, P) • (G', P') = (G + P·G', P·P')(11-11)

它的含义是：前一段的“产生/传递”与后一段的组合。这个运算是可结合的，所以可以用树的形式并行组合：N 位的进位只需 log₂N 级。

3.3 两种经典树：Kogge-Stone 与 Brent-Kung

Kogge-Stone（PPT 第 39、40 页）：每一级把“相距 1、2、4、8…”的段组合起来，共 log₂N 级，延时最小，但连线多、面积大。

图 3-1　Kogge-Stone 树：每一级把“相距 1、2、4、8”的段两两组合，共 log₂N 级（PPT 第 39 页）

Brent-Kung（PPT 第 42、43 页）：先用一棵“上行树”算出各段的前缀，再用“下行树”分发，延时 2log₂(N−1)，比 Kogge-Stone 慢一点，但连线少得多。

工程上的选择：要速度用 Kogge-Stone，要面积用 Brent-Kung，或者用两者的混合（如 Han-Carlson）。

4 进位旁路与进位选择：用“猜测”换时间

4.1 进位旁路（Carry-Bypass / Skip）

思想：如果一组 4 位的 P₀P₁P₂P₃ = 1（每一位都“传递”），那么这组的进位输出就等于进位输入，可以直接旁路过去，不必等内部逐级传播：

BP = P0P1P2P3; 若 BP = 1, 则 Co,3 = Ci,0(11-12)

于是整个加法器分成 N/M 块，块内串行、块间旁路。延时：

tadder = tsetup + M·tcarry + (N/M − 1)·tbypass + (M − 1)·tcarry + tsum(11-13)

对 M 求最优，得到 2M + N/M ≥ 2√(2N)，即最优分组 M ≈ √(N/2)——这就是“平方根”的由来。

4.2 进位选择（Carry-Select）

思想更暴力：两种可能都算。每组同时算“进位输入 = 0”和“= 1”两条链，等真正的进位到了，用多路选择器选一个：

tadd = tsetup + M·tcarry + (N/M)·tmux + tsum(11-14)

进一步把分组长度做成递增（2、3、4、5…），延时可以做到 O(√N)，称为“平方根进位选择加法器”。PPT 第 31 页有一句很实用的备注：“综合器里行波进位和进位选择是免费的，平方根进位选择是收费的。” 意思是前两种综合工具会自动优化，第三种需要专门的 IP。

5 乘法器：移位相加的并行化

5.1 基本算法

Z = X×Y = ΣiΣj xiyj·2i+j(11-15)

也就是“部分积（partial product）逐行生成、错位相加”。M 位 × N 位需要 N 个部分积、N−1 次加法。串行做要 N 个周期，并行做就是阵列乘法器。

5.2 阵列乘法器与它的瓶颈

阵列乘法器（PPT 第 45、46 页）把 N×M 个与门排成阵列，每个单元做一次全加，部分积沿斜线传递。它的关键路径：

tmult ≈ [(M−1) + (N−2)]tcarry + (N−1)tsum + tand(11-16)

图 5-1　4×4 阵列乘法器：部分积在阵列里逐行相加（PPT 第 45 页）

注意 t_sum 也在关键路径上，而且关键路径不唯一（图中两条虚线都是最坏路径）——这让优化很困难。

5.3 进位保留（Carry-Save）：只让进位走关键路径

进位保留乘法器（PPT 第 47 页）不把每一行的“和”与“进位”立刻相加，而是把它们保留下来、往下传，最后只用一个加法器统一处理：

tmult = (N−1)tcarry + tand + tmerge(11-17)

关键改进：关键路径只取决于 t_carry，与 t_sum 无关，而且唯一。 这为下一步的树形压缩铺平了道路。

5.4 Wallace 树：把部分积“压”成两行

Wallace 树（PPT 第 50 页）用全加器/半加器把每一列的部分积并行压缩：3 个输入压成 2 个输出（和 + 进位），逐级减少，最后只剩两行，再用一个快速加法器（§3 的树形加法器）合并。

延时 ∝ log(部分积个数)，是高性能乘法器的标准结构。代价是连线极不规则，版图上很难布，所以工业界常用“改进的 Booth 编码 + Wallace 树”的组合。

6 移位器：桶形与对数

6.1 桶形移位器

桶形移位器（barrel shifter）用一层传输管阵列实现“任意位数移位”：每一位的输出可以从输入的任意一位“选”过来。它的延时只有一级传输门，但面积由布线决定（N×N 的交叉阵列）。

6.2 对数移位器

用多级替代一层：第 1 级移 1 位、第 2 级移 2 位、第 3 级移 4 位……组合起来可以移任意位数。级数只有 log₂N：

级数 = log2N; 总线宽 ≈ pm(2K + 2K − 1)（K 为级数）(11-18)

对数移位器用“多级串联的延时”换“面积的指数下降”，是桶形移位器的标准替代方案。

7.2 五条核心结论

① 加法器的速度 = 进位的速度。所有优化都在压缩进位依赖。

② G/P/D 三种状态是快速进位的语言；C_o = G + P·C_i 是万能公式。

③ 点运算让进位可结合，于是能用树把延时压到 log N；Kogge-Stone 快、Brent-Kung 省。

④ 旁路/选择用“猜测”换时间，最优分组是 √N 量级。

⑤ 乘法器的关键是部分积压缩：进位保留让关键路径只依赖进位，Wallace 树把压缩变成 log 级。

8 自测题（含详解）

1. 写出全加器的 S 与 C_o，并说明 C_o = AB + (A+B)C_i 中两项的含义。

2. 为什么说“全加器全反相后功能不变”？这带来什么好处？

3. 16 位行波进位加法器、超前进位加法器的进位延时各约多少级门？（设 t_carry = 1 级）

4. 用点运算把 C_o,3 表示成树形组合。

5. 进位旁路加法器 N = 16，最优分组 M 是多少？总延时约多少？

6. 阵列乘法器与进位保留乘法器的关键路径差在哪？

7. 桶形移位器与对数移位器各有什么优缺点？

参考答案

1. S = A⊕B⊕Ci；C_o = AB + BCi + ACi。第一项 AB 是“产生进位”（G），第二项 (A+B)Ci 是“传递进位”（P）。

2. 因为 S̄(A,B,Ci) = S(Ā,B̄,C̄i)、C̄_o(A,B,Ci) = C_o(Ā,B̄,C̄i)。好处：相邻全加器可以交替用正/反相，进位链上不用插反相器，既省管子又省延迟（镜像加法器 24 管）。

3. 行波：15 级（(N−1)·t_carry）；超前进位：log₂16 = 4 级（点运算树）。差别约 4 倍。

4. C_o,3 = (G₃,P₃)•(G₂,P₂)•(G₁,P₁)•(G₀,P₀)，即 G₃ + P₃G₂ + P₃P₂G₁ + P₃P₂P₁G₀（再加初始进位项）。树形即两两组合，两级。

5. M ≈ √(N/2) = √8 ≈ 2.8，取 3~4；延时约 t_setup + 4 + (16/4−1)t_bypass + 3 + t_sum ≈ 10 级左右，比行波的 15 级快。

6. 阵列乘法器的关键路径包含 t_sum（且不唯一）；进位保留乘法器把“和”与“进位”分开传，关键路径只含 t_carry（且唯一），所以更快、更易优化。

7. 桶形：一级传输门，延时最小但面积 O(N²)、布线复杂；对数：log₂N 级，延时略大但面积小得多，是工程主流。
