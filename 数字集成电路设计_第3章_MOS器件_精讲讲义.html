0 导学：这一章在整门课中的位置

数字集成电路设计，说到底是用几百万个“开关”搭出会算数的电路。这个开关就是 MOS 晶体管（Metal-Oxide-Semiconductor Field-Effect Transistor，金属—氧化物—半导体场效应晶体管）。

但在真实芯片里，这个开关一点都不理想：导通时有电阻（决定电路能跑多快），关断时还在漏电（决定待机多费电），栅极和源漏结上挂着电容（决定每次翻转要充多少电荷），工艺一缩小还会冒出一堆“二阶效应”。第 3 章的任务，就是把这个开关彻底讲清楚：它内部长什么样、凭什么导通、导通后能流多大电流、电流怎么随电压变化、身上挂多大电容、这些量怎么变成一个能拿来算电路的模型。

0.2 为什么数字设计者也要懂器件

很多同学会想：我以后写 RTL、做架构，懂逻辑就够了，何必学器件物理？PPT 用了一个很贴切的类比：

PPT 第 4 页的类比

对于建筑师：了解预制件，才能构建复杂建筑。

对于 IC 设计人员：了解器件，才能设计集成电路。

建筑师不必会烧砖，但必须知道砖能承多重；数字设计者不必会做器件，但必须知道器件的“承重”——这就是本章反复强调的“对设计重要的器件特性参数”。

具体到数字电路，器件知识在五个地方直接决定你的设计好坏：

• 速度：门的延迟 ≈ Ron × C。Ron 来自 I–V 曲线，C 来自器件电容。不懂器件，你只能猜“这个门大概多快”。

• 功耗：动态功耗 = αCV²f，C 又是器件电容；静态功耗主要是亚阈值漏电，由 §8 的亚阈值斜率决定。

• 驱动能力与噪声容限：一个门能带几个门（fan-out）、输出高低电平够不够“硬”，取决于器件的 gm 和 I–V 形状。

• 面积：W/L 直接决定管子占多大地方，而面积就是钱。

• 可靠性：闩锁（latch-up）、ESD、热载流子、电迁移，全是器件级问题，往往是流片失败的直接原因。

PPT 还特别提醒了一个趋势：“曾经 MOSFET 最重要，现在互连线越来越重要”，原因是工艺按比例缩小后，晶体管变快，但连线相对变慢（RC 延迟随尺寸缩放规律不同）。所以第 4 章会专门讲互连线。但注意：这不是说器件不重要了，而是说“器件 + 互连线”必须一起建模，这也是 PPT 概要把两者并列的原因。

本章的真正目标

不是把你培养成器件工程师，而是让你能回答三个问题：

· 这个管子什么时候导通？（阈值电压 VT）

· 导通后能提供多大电流？（I–V 方程、k′、W/L）

1 器件长什么样：结构、符号与源漏判定

先给你一个画面。MOS 管本质上是一个“三明治”：最下面是硅衬底，中间是一层极薄的绝缘层（二氧化硅，几纳米厚），最上面是栅极（多晶硅或金属）。在栅极两侧的衬底里，嵌着两个掺杂类型与衬底相反的“小口袋”，分别叫源和漏。栅极加电压，就能把这两个口袋之间的表面“变成”一条导电通道——这就是 MOS 管全部的秘密。

最关键的两个人眼要盯住的尺寸：L 是“多晶硅栅跨在源漏之间的长度”，即沟道长度；W 是“有源区的宽度”，即沟道宽度。 版图上画出来的这两个尺寸，在电路公式里就是那个无处不在的 W/L。

版图上的 L ≠ 真正导电的 L

源漏注入时，杂质会横向扩散到栅极下方一小段距离，记为 LD（lateral diffusion）。所以真正导电的沟道长度是：

Leff = Ldrawn − 2 LD

0.25 μm 工艺 LD ≈ 0.02~0.03 μm，所以 Leff 比画出来的 L 略小。PPT 在讲栅电容时写的是 Leff，就是因为电容算的是真正存在沟道的那段面积。平时做手工估算，用 Ldrawn 已经够了。

现代 CMOS 工艺的做法是：整片硅是 p 型衬底，在其中挖出一个个 n 型“阱”，PMOS 坐在阱里，NMOS 直接坐在衬底上。所以 NMOS 的 B 是整片衬底（所有 NMOS 共用），PMOS 的 B 是它自己的 n 阱。这一点非常重要，因为它意味着：

• 所有 NMOS 的体电位是同一个（通常是 GND），不能各自独立调；

• 每个 n 阱可以独立接电位，所以 PMOS 的体电位可以分开控制（这就是后面“体偏置调节 VT”的基础）；

• n 阱 / p 衬底之间又形成一个大的 PN 结，它是 §8.6 闩锁效应的“主通道”。

1.4 源和漏到底怎么分（PPT 思考题）

PPT 第 7 页：两个 N⁺ 区，哪个是源，哪个是漏？

从结构上看，两个 N⁺ 区完全对称，没有任何区别。谁是源、谁是漏，不是由版图决定的，而是由外部电路的电位决定的。

规则：电位低的那一端是源。

理由：NMOS 靠电子导电，电子从低电位（源）出发、流向高电位（漏）。所以“源”是载流子的出发地，“漏”是载流子的目的地。

对 PMOS 反过来：空穴从高电位端进入沟道，所以电位高的那一端是源。统一说法是：源 = 载流子进入沟道的那一端。

这个定义有一个非常重要的推论：

MOS 是“对称器件”

MOS 管在结构上源漏可以互换（这一点和 BJT 的发射极/集电极不同）。在数字电路里，NMOS 的源通常接 GND、PMOS 的源接 VDD，所以“源”总是接在自己的电源轨上。

但当信号双向流动时（例如传输门、总线开关），源和漏会随信号互换。一旦互换，VSB 就变了，VT 跟着变（体效应），导通电阻也就跟着变——这是后面讲传输门时必须小心的地方。

别把 Drain 当成“漏电”

Drain 是“排走载流子”的意思，不是“漏电”。漏电叫 leakage，和漏极（drain）是两回事，中文翻译容易混。

1.6 零阶模型：一个开关加一个电阻

如果只关心“逻辑对不对”，可以把 MOS 看成理想开关：栅压够了就导通（短路），不够就断开（开路）。这就是零阶模型。它足够回答“这个门输出是高还是低”。

但一旦要算速度，就必须知道导通时到底有多大电阻。PPT 第 13 页把这件事讲得很清楚，这段话值得原样记住：

PPT 第 13 页：关键参数只有两个

· 开关阈值 VT：若输入只有低电平和高电平，则 V–I 特性不重要（只要保证导通/关断正确）。

· 导通电阻 Ron：若只考虑静态功能，则 Ron 不重要。

· 但要分析速度（RC 延迟），就必须知道 Ron；而计算 Ron 需要知道 V–I 特性（输出特性）。

PPT 的结论：右图那个“开关 + 电阻”的零阶简化模型，对大部分功能分析已经够用；但要分析速度，就得往下走到 I–V 曲线。

这就是本章的动机链条，也是本讲义后面几节的路线图：

逻辑正确 → 理想开关 → 导通电阻 Ron → I–V 特性 → 器件方程

第 3 节就是把这条链走完；第 7 节再把它变回一个“等效电阻”，好让你能算 RC 延迟。

1.7 寄生二极管：结构自带的“赠品”

具体来说：NMOS 的源、漏是 N⁺，衬底是 P 型，两者接触就形成 PN 结；PMOS 的源、漏是 P⁺，n 阱是 N 型，同样形成 PN 结。所以每一个 MOS 管都自带两个二极管（源-体、漏-体），而且 PMOS 所在的 n 阱和 p 衬底之间还有一个更大的二极管。

• 漏电：反偏结也有漏电流（§8.6 会讲 GIDL、结漏电），温度每升 10 ℃ 大约翻倍。

• 闩锁：一旦正偏，可能触发 CMOS 内部的可控硅结构，造成 VDD 到 GND 短路（§8.6）。

• 寄生电容：反偏结就是一个电容，它构成 §6 里 CSB、CDB 那一部分，直接拖慢电路。

• 衬底噪声耦合：数字开关的电流会通过衬底电阻变成噪声，干扰同片的模拟电路。

2 它是怎么导通的：反型层与阈值电压

第 1 节我们知道了管子长什么样，但还没回答最关键的问题：栅极上加电压，为什么就能让源和漏之间导电？ 这一节用“平板电容 + 电荷”的图像把这件事讲透，然后给出整个数字电路里最重要的一个参数——阈值电压 VT。

这里要建立一个关键认识：MOS 管不是“栅极电流控制”的器件，而是“栅极电压通过电容感应出电荷”的器件。 栅极下面有绝缘层，直流上几乎没有电流流进栅极（只有极小的隧穿/泄漏），所以 MOS 管的输入阻抗极高。这正是 CMOS 电路静态功耗极低的根本原因——栅极只在翻转时充放电，稳态时不耗电。

为什么叫“场效应”

MOSFET 全称里的 FET 就是 Field Effect Transistor（场效应晶体管）：用电场（而不是像 BJT 那样用基极电流）去控制沟道的导电能力。栅极上加的电压在氧化层和硅表面产生垂直电场，把载流子“吸”到表面或“推”走，从而改变沟道电阻。这就是“场效应”四个字的含义。

2.2 阈值电压的物理定义

所谓“阈值电压”，就是表面刚好出现足够多的反型电子、形成一条能导电的沟道所需要的最小栅压。判据是：表面势 ψs 达到 2φF，称为强反型判据。

φF = φT ln(NA / ni), φT = kT/q ≈ 26 mV（室温）(3-1)

其中 φF 叫费米势（Fermi potential），NA 是衬底掺杂浓度，ni 是本征载流子浓度（硅在室温约 1.5×10¹⁰ cm⁻³），φT 是热电压。对 p 型衬底，φF 取负值，所以 PPT 的公式里出现 −2φF，其数值就是 2|φF|，典型 0.6~0.9 V。

为什么偏偏是 2φF，不是 φF？

直观理解：p 型衬底里空穴是多数载流子，费米能级靠近价带。

第一步：把表面的费米能级“拉”到禁带中央（本征位置），需要表面势弯曲 |φF|，这时表面空穴浓度降到与本征浓度相当，叫耗尽。

第二步：继续弯曲，让表面的电子浓度等于体内的空穴浓度（n_surface = p_bulk），这才叫反型，还需要再弯 |φF|。

两步加起来就是 2|φF|。这也解释了为什么“强反型”是一个“约定”的判据——实际上从弱反型到强反型是连续过渡的（§8.1 的亚阈值区），工程上取 2φF 作为一个好用的分界点。

VT0 = φms − 2φF − QB0/Cox − Qss/Cox − QI/Cox(3-3)

两个必须记住的辅助公式：氧化层单位面积电容和耗尽层电荷。

Cox = εox / tox(3-4)
QB0 = √(2 q NA εsi |2φF|)(3-5)

其中 εox = 3.9ε0 ≈ 3.45×10⁻¹¹ F/m 是二氧化硅的介电常数，εSi ≈ 1.04×10⁻¹⁰ F/m，q = 1.6×10⁻¹⁹ C。0.25 μm 工艺 tox ≈ 5~6 nm，代进去 Cox ≈ 6 fF/μm²——这个数字要记住，它是后面所有电容估算的“单位面积价格”。

耗尽层电荷与宽度是怎么来的（PPT 第 15 页直接给了结果）

第一步：耗尽近似。假设耗尽区里没有可动载流子，只剩下固定的受主离子，电荷密度 ρ = −qNA（p 型衬底）。

第二步：解一维泊松方程 d²ψ/dx² = −ρ/εSi = qNA/εSi。边界条件：表面 x=0 处电场为 Es，耗尽区边缘 x=Wd 处电场为 0、电势为 0。

积分一次得电场线性分布 E(x) = qNA(Wd − x)/εSi，所以表面电场 Es = qNA·Wd/εSi；

再积分一次得表面势 ψs = qNA·Wd²/(2εSi)，反解出耗尽层宽度：

Wd = √(2 εsi ψs / (q NA))

第三步：求单位面积电荷。QB = qNA·Wd，把上式代进去：

QB = √(2 q NA εsi ψs)

第四步：代入强反型条件。VSB = 0 时 ψs = 2|φF|，得到 QB0 与 Wd0；当衬底加了反偏 VSB 时，ψs 变成 2|φF| + VSB，就得到 §2.5 的 QB 表达式。这就是体效应公式的全部来源，没有更多魔法。

2.5 体效应：衬底电压也能控制阈值

上面的推导已经暗示了一件事：如果源和衬底之间不是等电位，耗尽层的电荷就会变，阈值也跟着变。这个现象叫体效应（body effect），也叫背栅效应（back-gate effect）。

VT = VT0 + γ ( √(|2φF| + VSB) − √(|2φF|) )(3-6)
γ = √(2 q εsi NA) / Cox(3-7)

其中 γ 叫体效应系数（body-effect coefficient），单位是 V^0.5，0.25 μm 工艺里 NMOS 约 0.4 V^0.5。VSB = VS − VB 是源相对于体的电压。

物理图像很简单：把体电位拉低（对 NMOS 就是加反偏），耗尽层被“撑宽”，里面的固定电荷 QB 变多，栅极要先把这些电荷“付掉”才能反型，所以需要更大的栅压——VT 上升。

记忆要点：对 NMOS，源比体高（VSB > 0，即体更负）→ VT 变大；对 PMOS 则反过来，源比体低 → |VT| 变大。

图 2-1　阈值电压随体-源偏置变化（0.25 μm NMOS，PPT 第 19 页）

这张图的横轴符号要看清楚

PPT 文字说“衬底-源的偏置越负，VT 越大”，这句话是对的：衬底（体）相对源越负，就是反偏越深，VT 越大。

但右图横轴标的却是 VSB 从 0 到 −2.5，曲线从 0.85 V 一路降到 0.45 V。按公式 VT = VT0 + γ(√(|2φF|+VSB) − √|2φF|)，VSB 越正 VT 才越大，所以这张图实际上画的是 VBS（体相对源），或者说是“VSB 的相反数”。

体效应会带来两个直接后果，都和设计强相关：

• 串联堆叠的 NMOS 会变慢：例如 2 输入与非门的下拉链是两个 NMOS 串联，上面那个管子的源电位不是 0 而是中间节点电位，于是 VSB > 0，VT 变大，电流变小。这叫堆叠效应（stack effect），是后面估算门延迟时必须修正的一项。

• 体偏置可以当“旋钮”用：把 NMOS 的体接一个负电压（或 PMOS 的阱接高于 VDD 的电压），可以提高 VT、大幅降低漏电，这叫反向体偏置（RBB）；反过来叫正向体偏置（FBB），能降低 VT、提高速度，但漏电和闩锁风险都会上升。

正偏是危险的

对 NMOS，如果体电位比源高 0.6 V 以上，源-体那个寄生二极管就正偏导通了，会有大电流注入衬底——轻则漏电、重则触发闩锁（§8.6）。所以NMOS 的体永远是全片最低电位，PMOS 的体永远是最高电位，这不是随便接的，是保证所有 PN 结反偏。

2.6 为什么要“控制”阈值电压

PPT 第 16、17 页连续问了两次“控制阈值电压有什么用？”并在旁边写了答案：“速度与功耗之间的 trade-off”。这句话是整个低功耗设计的核心，值得展开讲。

先看 VT 怎么影响速度。所有电流公式都由过驱动电压 VGT = VGS − VT 驱动。在同样的电源电压 VDD 下：

• VT 降低 → VGT 变大 → 电流变大 → 给电容充放电更快 → 电路更快；

• VT 降低 → 关断时（VGS = 0）的亚阈值电流指数上升 → 待机漏电暴增（§8.1）。

VT 是怎么“做”出来的？主要有四个手段：

① 沟道注入（channel implant）：在沟道表面注入一层杂质，改变 QB 或 QI 项。这是最常用的手段，也是 VT 分档的主要方法。

② 栅极材料功函数：换金属栅材料（high-k/metal-gate 工艺），直接改 φms，可以做出相差几百 mV 的 VT。

2.7 例题与易错点

题：一个 NMOS 的 VT0 = 0.43 V，γ = 0.4 V^0.5，|2φF| = 0.6 V。求 (1) 体接地时；(2) 体接 −2 V（源接地）时的阈值电压。

解：

(1) VSB = 0，直接有 VT = VT0 = 0.43 V。

(2) 源接地 VS = 0，体接 −2 V，所以 VSB = VS − VB = 0 − (−2) = +2 V（反偏）。

VT = 0.43 + 0.4 × (√(0.6 + 2) − √0.6) = 0.43 + 0.4 × (1.612 − 0.775) ≈ 0.765 V

结论：体反偏 2 V，让 VT 从 0.43 V 涨到 0.765 V，相当于吃掉了 0.33 V 的过驱动电压。若 VGS = 2.5 V，过驱动从 2.07 V 降到 1.73 V，饱和电流大约下降到原来的 (1.73/2.07)² ≈ 70%，速度明显变慢。

这就是为什么堆叠的 NMOS 链、以及源不接地的管子（传输门、动态电路）都要额外留余量。

关于 VT 的四个常见错误

· 把 VT 当成一个“精确的开关刻度”。实际上它是统计量，同一片晶圆上不同位置的 VT 可能差 ±50~100 mV，温度每升高 1 ℃ 大约下降 0.5~2 mV。

· 体效应公式里 VSB 符号写反。记住定义 VSB = VS − VB，反偏时为正。

· 以为 VT 与 VDS 无关。短沟道器件里 VT 会随 VDS 增大而下降（DIBL，§8.3）。

· PMOS 的 VT 写成正的。PMOS 的 VT 是负值，用绝对值时才写 |VTP|。

3 电流从哪里来：长沟道 I–V 特性（完整推导）

这是全章最硬的一节，也是考试最容易失分的一节。但它的逻辑其实非常干净：栅压决定沟道里有多少电荷，漏源电压决定这些电荷跑多快，两者相乘就是电流。 PPT 把中间几步跳过了，这里一步步补全。

3.1 先建立物理直觉

把沟道想象成一条可变深度的水渠：

• 栅压 VGS 决定渠的深度（也就是沟道里的电荷密度）；

• 漏源电压 VDS 决定水的落差（也就是沿沟道的横向电场）；

• 水从源流向漏，流量就是电流 ID。

现在把落差从小到大调：

① 落差小时，渠深沿程几乎不变，流量与落差成正比——这就是线性区（也叫电阻区、三极管区），管子像一个电阻。

② 落差增大到某个程度，下游的渠被“抬起来”变浅，最后在漏端夹断（沟道厚度为零）。此时再加大落差，多出来的电压都降在夹断区那段耗尽层上，渠里的流量不再增加——这就是饱和区，管子像一个电流源。

③ 栅压不够（VGS < VT），渠根本没挖出来，一滴水也流不过去——截止区。

3.3 线性区：从电荷到电流

设源接地，沟道中位置 x 处的电位为 V(x)（从源的 0 变到漏的 VDS）。栅极与这一点之间的电压是 VGS − V(x)，所以要反型出沟道，本地需要的过驱动是 VGS − V(x) − VT。于是本地反型层电荷面密度为：

|Qn(x)| = Cox [ VGS − V(x) − VT ](3-8)

电荷在横向电场 E(x) = dV/dx 的驱动下以漂移速度 v(x) = μn·E(x) 运动，所以流过宽度 W 的电流为“电荷面密度 × 宽度 × 速度”：

ID = W |Qn(x)| v(x) = μn Cox W [ VGS − VT − V(x) ] dV/dx(3-9)

这个式子里 ID 是常数（连续性），V(x) 是变量。把 dx 乘到左边、把含 V 的项留在右边，从源（x=0, V=0）积分到漏（x=L, V=VDS）：

∫0L ID dx = μn Cox W ∫0V_{DS} [ VGS − VT − V ] dV(3-10)

左边 = ID·L；右边对 V 积分得 (VGS − VT)VDS − VDS²/2。整理后就是线性区的特性方程：

ID = kn' (W/L) [ (VGS − VT) VDS − VDS2/2 ](3-11)
kn' = μn Cox(3-12)

其中 kn′ 叫工艺跨导参数（process transconductance parameter），单位 A/V²。它只和工艺有关（迁移率 × 氧化层电容），W/L 才是设计者能调的部分。0.25 μm 工艺 kn′ ≈ 115 μA/V²，kp′ ≈ 30 μA/V²（PMOS 低得多，因为空穴迁移率低）。

PPT 用的另一种等价写法

PPT 第 20 页不是做积分，而是用“电荷 × 速度”的思路：把整条沟道看成一个整体，总电荷 Qc 除以渡越时间 t 就是电流，而渡越时间 t = L/v。

Qc = Cox W L ( VGS − VDS/2 − VT ) = ID · L / v

这里的关键是那个 1/2：沟道沿线的电位从 0 变到 VDS，所以平均过驱动电压是 VGS − VDS/2 − VT，而不是 VGS − VT。

再代入 v = μn·E = μn·(VDS/L)（把沟道看成均匀电场），整理就得到同一个式子。两种写法殊途同归，考试用哪种都对，但积分法更严谨，也更容易理解“为什么会饱和”。

3.4 深线性区与导通电阻

当 VDS 很小，小到 VDS ≪ 2(VGS − VT) 时，平方项 VDS²/2 可以忽略，线性区公式退化成一条过原点的直线：

ID ≈ kn' (W/L) (VGS − VT) VDS(3-13)

于是管子表现为一个由栅压控制的可变电阻：

Ron = VDS/ID = 1 / [ kn' (W/L) (VGS − VT) ](3-14)

这个式子非常重要，因为它一次性告诉你三件事：

• W 越大，Ron 越小（并联更多沟道）——所以驱动大负载要加宽管子；

• L 越小，Ron 越小——所以数字电路一律用最小 L；

• VGS 越大（过驱动越大），Ron 越小——所以电源电压越高，电路越快。这也解释了为什么降压能省电，但会变慢。

3.5 饱和区：夹断与平方律

把 VDS 继续增大。注意本地过驱动电压是 VGS − V(x) − VT，它在源端最大（V=0），在漏端最小（V=VDS）。当 VDS 增大到 VGS − VT 时，漏端的过驱动变成 0——沟道在漏端“厚度为零”，这就是夹断（pinch-off）。此时的漏源电压记为 VDSAT：

VDSAT = VGS − VT = VGT(3-15)

超过这个点之后，多出来的 (VDS − VDSAT) 全部降在夹断点与漏之间的耗尽区上，沟道从源到夹断点的形状基本不再变化，所以电流不再明显增大。把 VDS = VGS − VT 代回线性区公式，就得到饱和区电流：

ID,sat = (kn'/2)(W/L)(VGS − VT)2 = (kn'/2)(W/L) VGT2(3-16)

为什么是平方？因为过驱动电压 VGT 同时出现在两个地方：它既决定沟道里的电荷量（正比于 VGT），又决定夹断前的横向电场（也正比于 VGT），两个因子相乘就是平方。

由饱和区公式可以定义跨导 gm，它是“栅压变化一点，电流变化多少”的灵敏度：

gm = ∂ID/∂VGS = kn' (W/L) VGT = 2 ID / VGT(3-17)

数字电路里很少直接算 gm，但它是理解“增益”“驱动能力”“噪声容限”的关键：gm 越大，同样大小的输入扰动引起的输出电流变化越大，门的“硬度”越高。

3.6 沟道长度调制与输出电阻

真实的饱和区电流并不是一条水平线，而是略微上翘。原因是：VDS 增大时，夹断点会向源端移动一段 ΔL，有效沟道长度从 L 变成 L − ΔL，电流因此略微增加。这个效应叫沟道长度调制（channel-length modulation），PPT 用参数 λ 来描述：

ID = (kn'/2)(W/L)(VGS − VT)2 (1 + λ VDS)(3-18)

λ 的单位是 V⁻¹，0.25 μm 工艺 NMOS 约 0.06 V⁻¹。它对设计的含义是：

• λ ∝ 1/L：沟道越短，ΔL/L 越大，λ 越大，曲线越斜，越不像理想电流源。这就是 PPT 说的“λ 与沟道长度 L 成反比”。

• 输出电阻 ro = 1/(λ·ID)：饱和区里管子的等效输出电阻。λ 越大，ro 越小，增益越低。数字电路里 ro 影响的是“输出高电平能被拉多高”，但在全摆幅 CMOS 里通常不是主要矛盾。

• 模拟电路里 λ 是坏东西，会降低增益；数字电路里它主要影响精确的电流估算。

3.9 W 和 L：谁是设计参数

PPT 第 22 页圈出了公式里的 W，然后问了一个非常好的问题：“W 是设计参数，VGS（VDD）是工作参数，L 是设计参数吗？”

答案

3.10 例题：手算一条 I–V 曲线

题：0.25 μm NMOS，kn′ = 115 μA/V²，VT0 = 0.43 V（体接地），W = 1 μm，L = 0.25 μm，VGS = 2.5 V。求 VDS = 0.1 V、0.5 V、2.5 V 时的 ID，以及深线性区的 Ron。

第一步：判断工作区。VGT = 2.5 − 0.43 = 2.07 V，所以 VDSAT = 2.07 V。W/L = 1/0.25 = 4。

第二步：VDS = 0.1 V < 2.07 V → 线性区：

ID = 115×10−6 × 4 × [2.07×0.1 − 0.01/2] ≈ 93 μA

（此时 VDS 远小于 2VGT ≈ 4.1 V，可以用深线性区近似 ID ≈ kn′(W/L)VGT·VDS ≈ 95 μA，误差很小。）

第三步：VDS = 0.5 V < 2.07 V → 仍是线性区：

ID = 115×10−6 × 4 × [2.07×0.5 − 0.25/2] = 460×10−6 × 0.91 ≈ 419 μA

第四步：VDS = 2.5 V ≥ 2.07 V → 饱和区（先忽略 λ）：

ID = 0.5 × 115×10−6 × 4 × 2.072 ≈ 985 μA

计入 λ = 0.06 V⁻¹ 的沟道长度调制：ID × (1 + 0.06×2.5) = 985 × 1.15 ≈ 1.13 mA。

第五步：深线性区导通电阻：Ron = 1/[115×10⁻⁶ × 4 × 2.07] ≈ 1.05 kΩ。

点评：1 kΩ 量级是 0.25 μm 工艺的典型值。记住这个数量级，后面算 RC 延迟时（例如 1 kΩ × 10 fF = 10 ps）就能快速估出电路速度。

重要提醒：上面用的是长沟道公式，而 0.25 μm 的管子其实是短沟道，实测电流会小很多（见 §4 的例题，约只有一半）。这正是本节标题写“长沟道”的原因。

3.12 本节易错点汇总

长沟道 I–V 的六个坑

· 没判断工作区就套公式。正确顺序：算 VGT → 比较 VDS 与 VGT → 选公式。

· 把“饱和”理解成“电流完全不变”。那是一阶近似，实际有 λ 造成的上翘。

· 线性区也叫“三极管区/电阻区”，不要和“放大器工作在线性放大区”混淆，两个“线性”含义不同。

· 过驱动电压 VGT = VGS − VT 才是真正驱动电流的量，不是 VGS 本身。所有“为什么电源降低后变慢”的问题，答案都在这里。

· kn′ 与 kn 别混：kn′ = μnCox 是工艺参数（A/V²）；kn = kn′(W/L) 才是这个管子的参数（A/V²）。

· W/L 是无量纲的比。有人会忘记 L 也要换算成 μm 再相除。

4 短沟道器件：速度饱和与提前饱和

第 3 节的所有公式，都建立在一个前提上：沟道足够长，载流子可以自由加速。但当 L 缩到 1 μm 以下，尤其是 0.25 μm、90 nm、28 nm 时，这个前提崩了。这一节讲清楚“崩在哪”以及“崩了以后用什么公式”。

① 速度饱和（velocity saturation）

载流子速度有上限 vsat，不能无限随电场增加

电流提前饱和、饱和电流大幅下降、ID 与 L 的关系变弱

② 迁移率退化（mobility degradation）

垂直方向的高栅场把载流子压向界面，散射增强，μ 下降

大 VGS 下电流增长变慢（不再是平方律）

③ 沟道长度调制加剧

L 短，ΔL/L 占比大，λ 变大

输出特性更斜、输出电阻更低

④ 电荷共享 / DIBL（补充）

源漏耗尽区占据了沟道电荷的一部分；漏压能降低源端势垒

VT 随 L 减小而下降（roll-off）、随 VDS 增大而下降

4.2 速度饱和：载流子也会“限速”

在低电场下，载流子的漂移速度与电场成正比：v = μE，斜率就是迁移率 μ。但电场大到一定程度后，载流子不断与晶格碰撞（光学声子散射），速度不再增加，趋于饱和值 vsat。

v = μ E / (1 + E/Ec) → v → vsat（当 E ≫ Ec）(3-19)

其中 Ec 叫临界电场，硅中电子约 1.5 V/μm（PPT 上写的 Ec = 1.5 就是这个数），vsat ≈ 1×10⁵ m/s（也就是 1×10⁷ cm/s）。

PPT 上那个 μsat = 10⁵ 是什么？

PPT 第 31 页在图上方标了 μsat = 10⁵，但纵轴写的是 μn（m/s）——其实这里画的不是迁移率，而是漂移速度 v，10⁵ 的单位是 m/s。

正确说法：饱和速度 vsat ≈ 10⁵ m/s。迁移率 μ 的单位是 cm²/(V·s) 或 m²/(V·s)，不可能等于 10⁵。这个笔误在看课件时要注意，考试别跟着写错。

顺带记住数量级：电子 vsat ≈ 10⁷ cm/s，空穴 vsat ≈ 0.6~0.8×10⁷ cm/s。

4.3 VDSAT 的来历

长沟道里，沟道横向电场近似为 E ≈ VDS/L。当这个电场达到 Ec 时，漏端的载流子速度就饱和了，此时对应的漏源电压就是饱和电压 VDSAT：

VDSAT = L vsat / μn （令 μn VDSAT/L = vsat 解出）(3-20)

注意这个式子的物理含义：VDSAT 与 L 成正比。L 越小，VDSAT 越小——也就是说，短沟道器件在更低的漏压下就进入饱和了。这就是“提前饱和”。0.25 μm 工艺 NMOS 的 VDSAT ≈ 0.63 V（工艺参数表给出），远小于同条件下长沟道的 VGS − VT ≈ 2 V。

4.4 提前饱和与输出特性

图 4-1　长沟道（左）与短沟道（右）的输出特性对比：注意纵轴电流值、饱和点的位置，以及“饱和”后仍明显上翘的斜率（PPT 第 29 页）

对照这两张图，短沟道器件有三个肉眼可见的差别：

① 饱和点提前：左图在 VDS ≈ 1.5~2 V 才饱和，右图在 VDS ≈ 0.5~0.6 V 就拐弯了，正好对应 VDSAT ≈ 0.63 V。PPT 把这种“早早饱和”标为 Early Saturation，中文课上写作“欧拉饱和”，标准译名是厄利（Early）饱和 / 早期饱和。

② 饱和电流大幅下降：同样 VGS = 2.5 V，左图约 5.4×10⁻⁴ A，右图只有约 2.2×10⁻⁴ A，少了约 60%。原因是速度封顶后，沟道电荷再多也跑不快，电流上不去。

③ 拐点变“圆”：长沟道是从线性区到饱和区的硬拐点，短沟道是一个平滑的过渡（因为沟道里只有一部分区域速度饱和）。这个“圆角”是短沟道器件最典型的特征，仿真曲线上非常明显。

还有一个细节：短沟道曲线在饱和区上翘得更厉害（斜率更大），因为 λ 更大（λ ∝ 1/L）。PPT 在旁边特意写了“注意电流值与饱和电流间隔”，提醒你两件事：电流绝对值变小了，相邻 VGS 曲线之间的间距也变小了（不再是严格的平方关系）。

4.5 短沟道电流公式与“与 L 无关”

把速度饱和代进电流表达式：ID = W·|Qn|·v，在夹断点处 |Qn| = Cox(VGT − VDSAT)，v = vsat，于是：

ID,sat ≈ vsat Cox W ( VGT − VDSAT/2 )(3-21)

当强速度饱和时（VDSAT ≪ VGT），可以进一步近似为：

ID,sat ≈ vsat Cox W VGT(3-22)

这个式子里没有 L！ 这就是 PPT 第 33 页那个提问的答案：

PPT 第 33 页：ID 与 L 的关系？无关，还是反比？

长沟道：ID ∝ 1/L（反比），因为 L 越长，同样的电压下落越平缓、电场越弱。

强速度饱和：ID ≈ vsat·Cox·W·VGT，与 L 无关，只正比于 W。

实际情况（0.25 μm 属于“部分速度饱和”）：介于两者之间，ID 仍有微弱的 1/L 依赖，但远弱于长沟道。

设计含义：这就是为什么进入深亚微米后，“缩小 L 提高速度”的收益变小了——器件尺寸缩小带来的性能提升，有相当一部分被速度饱和“吃掉”了。工程师于是转向提高 vsat（应变硅）、降低 Cox 的等效厚度、或用新结构（§9）。

PPT 上那个带 ½μnCox 的“速度饱和”公式

PPT 第 30、31 页写了：速度饱和区 ID = ½μnCox(W/L)(VGS−VT)² × VDSAT。这个式子的来源是“把长沟道饱和公式乘上 VDSAT”，量纲上说得通，但它会给出 ID ∝ VGT²，与“速度饱和下 ID ∝ VGT”的物理结论矛盾。

建议记这个版本：ID = vsat·Cox·W·(VGT − VDSAT/2)，既符合物理，也与 §4.7 的统一模型自洽。

考试如果按 PPT 写法给分，你两种都写一遍最稳；但理解要按物理来。

4.6 转移特性从抛物线变直线

图 4-2　转移特性对比：长沟道是抛物线（ID ∝ VGT²），短沟道接近直线（ID ∝ VGT）（PPT 第 30 页）

这个变化的意义很大：

• 长沟道：ID ∝ (VGS − VT)² → 曲线越往右越陡，跨导 gm 随 VGS 线性增长；

• 短沟道：ID ∝ (VGS − VT) → 近似直线，gm 基本是常数（≈ vsat·Cox·W）；

• 对数字电路的影响：短沟道器件的“开”与“关”之间的过渡更“线性”，这意味着电压传输特性（VTC）的过渡区更宽，噪声容限略有下降；但另一方面，同样的 VGS 变化能得到更可预测的电流，设计反而更“线性”。

• 对模拟电路的影响：平方律失效，所以模拟设计在深亚微米下不能再用平方律手算，必须依赖 gm/ID 方法或查表。

4.8 对设计的意味

题：用短沟道模型重算 §3.10 的饱和电流，并与长沟道结果对比。已知 VDSAT = 0.63 V，其余参数不变（W/L = 4，kn′ = 115 μA/V²，VGT = 2.07 V）。

解：Vmin = min(2.07, VDS, 0.63)。在 VDS ≥ 0.63 V 时，Vmin = 0.63 V，落在“速度饱和区”：

ID = 115×10−6 × 4 × (2.07×0.63 − 0.632/2) = 460×10−6 × (1.304 − 0.198) ≈ 509 μA

对比：长沟道公式给出 985 μA（不计 λ），短沟道只有 509 μA，约为一半。这与 PPT 第 29 页两张图的纵轴比例（2.2×10⁻⁴ vs 5.4×10⁻⁴，约 41%）基本吻合（差异来自迁移率退化等本讲义未计入的效应）。

结论：用长沟道公式估算深亚微米器件，会高估电流约一倍，从而低估延迟。 做作业时如果题目给了 VDSAT，就说明要用短沟道模型。

最后总结这一节给设计者的四条启示：

• 速度饱和让“缩小 L”的收益递减：ID 不再 ∝ 1/L，所以缩小尺寸主要收益变成“面积小、电容小”，而不是“电流大”。

• 短沟道器件更像“电流源”：输出特性更平（虽然 λ 更大），线性区更短，所以数字电路里管子大部分时间工作在饱和区。

• VDSAT 是一个重要的设计参数：它决定了输出摆幅、电流源的最小工作电压（模拟里的“裕度”），也在工艺参数表里单独列出。

• 模型必须带 λ 和 VDSAT 才准：只背平方律，在 0.25 μm 以下会错得很离谱。

5.3 例题：算 ID、gm、ro、Ron

题：0.25 μm NMOS，W = 2 μm，L = 0.25 μm，VGS = 2.5 V，VDS = 2.5 V，体接地。用工艺参数表求 ID、gm、ro、Ron，并判断工作区。

第一步：算基本量。W/L = 8；VGT = 2.5 − 0.43 = 2.07 V；因为 VDSAT = 0.63 V < VGT，且 VDS = 2.5 V > VDSAT，所以工作在速度饱和区。

第二步：算电流（统一模型，Vmin = VDSAT = 0.63 V）：

ID = 115×10−6 × 8 × (2.07×0.63 − 0.632/2) ≈ 920×10−6 × 1.106 ≈ 1.02 mA

再用 λ 修正：ID × (1 + 0.06×2.5) = 1.02 × 1.15 ≈ 1.17 mA。

第三步：跨导。饱和区 gm ≈ kn′(W/L)·VGT（长沟道式），短沟道下更接近 gm ≈ 2ID/VGT：

gm ≈ 2ID/VGT = 2×1.17×10−3/2.07 ≈ 1.13 mA/V

第四步：输出电阻。ro = 1/(λ·ID)：

ro = 1/(0.06 × 1.17×10−3) ≈ 14.2 kΩ

第五步：深线性区导通电阻（把 VDS 压到很小）：

Ron = 1/[k'(W/L)VGT] = 1/(115×10−6 × 8 × 2.07) ≈ 525 Ω

解读：Ron ≈ 0.5 kΩ、ro ≈ 14 kΩ，两者差 28 倍。这说明了为什么数字电路里“开”和“关”的等效电阻差别巨大，也说明了为什么不能用同一个电阻模型算所有情况。（§7 会给出“放电过程”的等效电阻 Req ≈ 1.3 kΩ，介于两者之间。）

• VT 随温度升高而降低（约 −0.5~−2 mV/℃），而迁移率随温度升高也降低，两者部分抵消，所以 MOS 电流的温度特性不像双极型那么敏感——这正是 CMOS 的一大优点。

• 失配（mismatch）：两个相邻的、设计相同的管子，VT 也会有随机差异，标准差近似为 σ(ΔVT) = A_VT/√(W·L)，其中 A_VT 是工艺常数（几 mV·μm）。这解释了为什么面积越大，匹配越好（也是模拟电路喜欢大管子的原因）。

设计者怎么对付波动

· 留余量（margin）：时序上留 10%~20% 的 slack；

· 用 Monte Carlo 仿真统计延迟/漏电分布，而不是只看一个数；

· 标准单元库本身就按 worst-case 表征，所以你用库算出来的延迟已经含了余量；

· 关键路径用 LVT、非关键路径用 HVT，把“快”花在刀刃上（§2.6）。

6 动态行为（一）：电容

到这里为止，我们讲的都是“稳态”：给定电压，电流多大。但数字电路的本质是翻转——把节点从 0 充到 1、再从 1 放到 0。决定翻转快慢的，不是电流本身，而是“要搬多少电荷”，也就是电容。这一节把管子的电容拆开算清楚。

6.1 为什么数字设计者最关心电容

三个最基本的公式，全部和 C 有关：

Q = C V （搬多少电荷）(3-25)
I = C dV/dt → t ≈ C V / I （翻转需要多长时间）(3-26)
E = (1/2) C VDD2 （每次 0→1 翻转消耗的能量）(3-27)

再乘以翻转频率和门的数量，就是整颗芯片的动态功耗：P = α C VDD² f。所以：

• 电容决定延迟：延迟 ≈ Req × C，C 越大越慢；

• 电容决定功耗：C 越大越费电；

• 电容决定耦合噪声：两条线之间的耦合电容会把一条线的翻转“灌”到另一条线上（第 4 章）。

一句话：数字电路设计，一半的工作就是在“减小电容”和“加大驱动”之间做平衡。

看出规律了吗？栅极的总电容基本一直是 Cox·W·Leff 这个量级，变的只是“分给谁”：

• 截止时全给体（CGB），因为沟道没形成；

• 线性区一半给源一半给漏，因为沟道从源到漏是均匀的；

• 饱和区几乎全给源（⅔），因为漏端已经夹断，与栅的耦合断了。

这对电路意味着什么？ 一个门在翻转过程中，输出端的管子会从饱和区滑到线性区，CGS/CGD 的分配一直在变。所以严格计算要用电荷守恒（Q = ∫C dV），工程上用“平均电容”近似就够了。

为什么饱和区是 ⅔ 而不是 ½

在线性区，沟道电荷沿程均匀，栅电容自然是 ½ + ½。到了饱和区，漏端夹断，沟道电荷沿程分布不再是常数，而是：

q(x) = Cox VGT √(1 − x/L)

（这个分布由 V(x) = VGT[1 − √(1 − x/L)] 得到，是平方律模型的直接结果。）

把 q(x) 沿沟道积分得到栅下总电荷：

Qg = W Cox VGT ∫0L √(1 − x/L) dx = (2/3) Cox W L VGT

所以饱和区栅-沟道总电容 = ⅔Cox·W·L。又因为漏端已经夹断、与栅极的耦合几乎断掉，工程上干脆把这份总电容全部记到源端：CGS = ⅔Cox·W·Leff，CGD ≈ 0。这是教材和 PPT 共同采用的模型约定；严格做电荷分配会比 ⅔ 略小，但工程模型一律按 ⅔ 取。

记忆方法：⅔ 这个数来自 √(1−x/L) 的积分，本质是“三角形沟道比矩形沟道少一点点”。不必每次推，但要记住这个数的来源。

6.5 覆盖电容与有效沟道长度

版图上，栅极的两端一定会和源/漏扩散区重叠一段距离（工艺对准容差要求），这段重叠产生的电容叫覆盖电容（overlap capacitance），它不随工作区变化：

CGSO = Cox W LD, CGDO = Cox W LD(3-28)

其中 LD 是横向扩散长度（0.25 μm 工艺约 0.05 μm）。PPT 参数表里的 Co = 0.31 fF/μm 就是“单位宽度的覆盖电容” Cox·LD，所以一个宽度为 W 的管子，每侧覆盖电容就是 Co·W。

同时，因为源漏向栅下扩散了 LD，真正导电的沟道长度变短了：

Leff = Ldrawn − 2 LD(3-29)

这就解释了 PPT 为什么在栅电容表里用 Leff 而不用 L：电容算的是真正存在沟道的那段面积。平时估算直接用 L 也行，误差在 10%~20%。

6.6 结电容：面积项加周长项

源/漏扩散区与衬底之间是反偏的 PN 结，它的电容由两部分并联而成：

Cdiff = Cj × AREA + Cjsw × PERIMETER(3-30)

对一个长为 LS（沿沟道方向）、宽为 W（沿沟道宽度方向）的扩散区：

Cdiff = Cj LS W + Cjsw (2 LS + W)(3-31)

为什么有周长项？ 因为扩散区是个“浅盒子”，除了底面，四个侧面（侧壁，sidewall）也和衬底形成结。侧壁的面积 = 周长 × 结深 xj，所以它正比于周长，用单位长度的电容 Cjsw 来描述。面积项叫“底板电容”，周长项叫“侧壁电容”，两者必须分开算。

结电容还是偏压的函数——反偏越深，耗尽层越宽，电容越小：

Cj = Cj0 / (1 − VD/φ0)m(3-32)

其中 Cj0 是零偏电容，VD 是结上的电压（反偏时取负值，所以分母 > 1，电容变小），φ0 是内建电势（约 0.9 V），m 是梯度系数：突变结 m ≈ 0.5，线性渐变结 m ≈ 0.33（PPT 上写 0.3 与 0.5，是同一件事的两种取法）。

这条曲线在 VD 接近 φ0（正偏）时会急剧上升——这就是为什么源漏电压摆幅不能超过电源轨，否则结电容会暴涨、甚至正偏导通。

6.7 例题：算一个管子的总电容

题：0.25 μm NMOS，W = 1 μm，L = 0.25 μm，工作在饱和区。已知 Cox = 6 fF/μm²，Co = 0.31 fF/μm，Cj = 2 fF/μm²，Cjsw = 0.28 fF/μm，扩散区长度 LS = 0.6 μm。求栅极总电容与漏极结电容。

① 栅-沟道电容（饱和区，用 Leff ≈ L = 0.25 μm）：

CGS,ch = (2/3) Cox W L = (2/3) × 6 × 1 × 0.25 = 1.0 fF

② 覆盖电容（两侧各一份）：

CGSO = CGDO = Co W = 0.31 × 1 = 0.31 fF

③ 栅极总电容（从栅极看进去）：

Cgate = 1.0 + 0.31 + 0.31 ≈ 1.62 fF

④ 漏极结电容（放电时这个电容才真正被充放）：

CDB = Cj LS W + Cjsw(2LS + W) = 2×0.6×1 + 0.28×(1.2+1) ≈ 1.2 + 0.62 = 1.82 fF

⑤ 结论：这个管子的栅电容约 1.6 fF，漏极结电容约 1.8 fF。两者量级相当——这一点非常重要：在深亚微米工艺里，结电容（寄生）和栅电容（本征）已经一样大了，不能只算栅电容。

数量级感：1 fF 量级 × 1 kΩ ≈ 1 ps。一个反相器带一个同样的反相器，延迟大约 10~30 ps——这就是 0.25 μm 工艺的速度量级。

6.8 设计含义

把这一节的结论翻译成设计规则：

① 栅电容正比于 W：加大 W 提高驱动，但会线性增加前级的负载。所以“把管子加宽”不是免费的，加到一定程度收益递减——这就是为什么要用缓冲器链（buffer chain）逐级放大，而不是一个门直接驱动大负载。

② 结电容正比于扩散区面积 + 周长：所以版图上要尽量减小源漏面积。常用手法是多指结构（multi-finger）：把一个 W = 10 μm 的管子拆成 10 个 W = 1 μm 的“手指”并联，相邻手指共享源漏扩散区，总面积和总周长都大幅下降。

③ CGB 只在截止区出现：所以“关断的管子”并不是完全“透明”的，它的栅极仍然挂着 Cox·W·L 的电容，会影响前级的负载。

④ CGD 是米勒电容：它跨接在输入和输出之间，会造成“输出跳变耦合回输入”，在动态电路和放大器中是大问题。数字电路里它主要影响翻转过程中的充放电。

⑤ 别忘连线电容：第 4 章会看到，在 0.25 μm 以下，金属连线对地的电容往往比器件电容还大。

【一句话记住】

栅电容 ≈ Cox·W·L（分给谁看工作区）；结电容 ≈ Cj·面积 + Cjsw·周长（看版图）。 记住这两句，绝大多数电容估算题都能下手。

7 动态行为（二）：导通电阻 Req

第 6 节讲了电容，第 7 节讲电阻。两者一乘，就是数字电路里最常用的延迟模型：t ≈ Req × C。问题是，MOS 管的电阻并非常数——它随电压变化。这一节讲怎么把它“压”成一个好用的常数。

7.1 为什么需要等效电阻

考虑一个最简单的场景：一个 NMOS 给一个电容 C 放电（这是每个门翻转时都在发生的事）。严格求解需要解微分方程，因为放电电流随 VDS 变化：

C dVout/dt = − ID(Vout)(3-33)

这个方程一般没有解析解（ID 是分段函数）。工程上的做法是：找一个常数电阻 Req，使得用 RC 放电公式算出来的延迟，和真实情况足够接近。 这就把非线性问题变成了一个初中生都会算的 RC 问题。

7.2 Ron 为什么不是常数

图 7-1　放电过程中工作点在 I–V 曲线上滑动：起始于 VDS = VDD（电流最大），终止于 VDS = 0（电流为零）（PPT 第 36 页）

看图就明白了：放电开始时，VDS = VDD，管子工作在饱和区，电流是 IDSAT；随着电容放电，VDS 逐渐减小，工作点沿曲线向左滑，经过拐点进入线性区；最后 VDS → 0，电流也趋于 0，此时“瞬时电阻” R0 = VDS/ID 反而变得很大。

所以：

• R0（VDS → 0 处）= 深线性区电阻，数值最小（§3.4 那个 1/(k′(W/L)VGT)）；

• Rmid（VDS = VDD/2 处）比 R0 大一些，因为此时电流已经不含 VDS 的线性项；

• 整个放电过程的有效电阻，介于两者之间——这就是 Req。

7.3 Req 的推导

PPT 给的做法是“取两个工作点的平均”：一个在放电刚开始（VDS = VDD），一个在放电中段（VDS = VDD/2）：

Req = (1/2) [ VDD/(IDSAT(1+λVDD)) + (VDD/2)/(IDSAT(1+λVDD/2)) ](3-34)

为什么取这两点？ 因为电容电压从 VDD 降到 0 的过程中，“贡献最大”的是中间那段（电压变化最快、电流最大），取中点和起点的平均，是一个既简单又足够准的经验做法。

当 λVDD 比较小（可以忽略）时，上式化简为：

Req ≈ (3/4) (VDD/IDSAT)(3-35)

3/4 是怎么来的？ 令 λ = 0：第一项 = VDD/IDSAT，第二项 = (VDD/2)/IDSAT，取平均 = (1/2)(1 + 1/2)(VDD/IDSAT) = 3/4 · VDD/IDSAT。就这么简单。

考虑 λ 的一阶修正，PPT 给出：

Req ≈ (3/4)(VDD/IDSAT) (1 − (5/6) λ VDD)(3-36)
为什么不是“直接用 R0”？

因为放电/充电的大部分时间，管子并不在 VDS ≈ 0 的深线性区，而是在饱和区或拐点附近，那里的电流只有 IDSAT 的 1/2 到 1 倍。用 R0 会严重低估延迟。

反过来，用 VDD/IDSAT（饱和区电阻）又会高估延迟，因为末段管子进入线性区、电阻变小。两者折中就是 3/4 这个系数。

这也解释了一个常见现象：手算延迟通常比 SPICE 略大（保守），工程上正合适——宁可留余量。

7.4 例题与数量级

题：0.25 μm NMOS，W/L = 4（W = 1 μm），VDD = 2.5 V，VGS = VDD 时 IDSAT ≈ 509 μA（§4.8 的短沟道值），λ = 0.06 V⁻¹。求 Req，并估算驱动 10 fF 负载的延迟。

① 用完整公式：

Req = (1/2)[2.5/(509μ×1.15) + 1.25/(509μ×1.075)] ≈ (1/2)[4273 + 2285] ≈ 3.28 kΩ

② 用简化式核对：

Req ≈ 0.75 × 2.5/(509×10−6) × (1 − (5/6)×0.06×2.5) ≈ 3684 × 0.875 ≈ 3.22 kΩ

两者吻合（3.2~3.3 kΩ），说明简化式够用。

③ 延迟估算（一阶 RC）：

tp ≈ 0.69 Req C = 0.69 × 3.28 kΩ × 10 fF ≈ 23 ps

④ 数量级感：0.25 μm 工艺、W/L = 4 的管子，驱动 10 fF 大约 20 ps 量级。如果你的仿真结果差了 10 倍，一定是哪里错了——这就是手算的价值。

⑤ 加大 W 的效果：若 W/L 加到 10，IDSAT ≈ 1.27 mA，Req ≈ 1.3 kΩ，延迟降到约 9 ps。但栅电容也从 1.6 fF 增到 4 fF，前级的负担变重了——这正是 §6.8 说的“加宽不是免费的”。

7.5 Req 用在哪里

• 延迟估算：最常用。t = 0.69·Req·C（一阶），或多级用 Elmore 延迟公式累加。

• 驱动能力比较：Req 越小，驱动越强。单元库里每个门的“驱动强度”（X1、X2、X4……）本质上就是 Req 的倒数关系。

• 功耗估算：短路功耗（翻转瞬间 VDD 到 GND 直通）正比于 Req 上的电流，所以 Req 也影响动态功耗中的短路分量。

• 噪声分析：输出电阻决定了节点对外部干扰的“硬度”，Req 越小越抗干扰。

【一句话记住】

Req ≈ 0.75·VDD/IDSAT（λ 小的时候）；延迟 ≈ 0.69·Req·C。 这两个式子能让你在没有任何工具的情况下，30 秒估出一个门的延迟量级。

8 非理想效应：亚阈值、闩锁与短沟道效应

前面七节讲的是“理想器件”。真实器件还有一堆“不听话”的行为，它们决定了待机功耗、可靠性和良率。PPT 只讲了两件事——亚阈值电流和闩锁，这里把最常考的几项都补齐，并标注哪些是补充内容。

8.1 亚阈值导电：关不断的那部分电流

第 3 节说“VGS ≤ VT 时 ID = 0”。这在长沟道、室温下是个不错的近似，但真实器件在 VGS 低于 VT 时仍有电流，而且这个电流随 VGS 指数变化。这个区域叫亚阈值区（subthreshold region）或弱反型区。

物理原因：当 VGS 接近但还没到 VT 时，表面已经有少量电子（弱反型），它们不是靠“漂移”过沟道，而是靠浓度梯度扩散过去。扩散电流天然是指数关系：

ID ≈ I0 eqV_{GS/(nkT)} = I0 eV_{GS/(nφT)}(3-37)

其中 n 叫亚阈值斜率因子（subthreshold swing factor），典型 1.2~1.5，反映栅极对沟道电位的控制能力（理想是 1.0，但界面态和电容分压让它大于 1）。

图 8-1　转移特性的完整版（半对数坐标）：VGS < VT 是指数段，刚过 VT 是平方段，VGS 很大后趋于线性（PPT 第 44 页）

这张图比第 3 节那张线性坐标的图“诚实”得多：它把纵轴换成对数，于是你第一次看到——“关断”的器件，电流从 10⁻¹² A 一路指数爬升到 10⁻⁴ A，跨越了 8 个数量级，而这一切都发生在 VGS 从 0 到 0.5 V 的区间里。

8.2 亚阈值斜率与低电压设计

工程上用一个更直观的指标描述这段指数曲线：亚阈值斜率 S，定义是“电流变化 10 倍所需的栅压变化”：

S = n (kT/q) ln(10) ≈ n × 60 mV/decade（室温）(3-38)

PPT 给的典型值是 60~100 mV/十倍（写的是 60~100 mV）。60 mV/decade 是理论极限（n = 1，由热电压决定），实际器件因为界面态和电容分压，n 在 1.2~1.5，所以 S 在 70~90 mV/decade。

题：某工艺 S = 80 mV/decade，VT = 0.4 V，VGS = 0 时 ID = 10 nA。求 VT 降低 100 mV 后，关态电流变成多少？

解：电流每降 80 mV 变化 10 倍。VT 降低 100 mV，相当于 VGS 相对 VT 增加了 100 mV：

Ioff' = Ioff × 10100/80 = 10 nA × 101.25 ≈ 10 nA × 17.8 ≈ 178 nA

结论：VT 只降了 100 mV，关态漏电涨了 18 倍。这就是为什么“降低 VT 换速度”是一笔危险的交易——功耗会指数爆炸。

延伸：整颗芯片如果有 10⁸ 个管子，每个漏 178 nA，总漏电就是 17.8 A——芯片直接烧掉。所以低功耗设计的第一原则是：该关的必须关得住。

PPT 第 45 页那张图（两条不同 VT 的曲线）想说的就是这个道理：VT = 0.1 V 的器件在 VGS = 0 时漏电比 VT = 0.4 V 的高出好几个数量级。图下方那句英文 “Leakage control is critical for low-voltage operation”（漏电控制对低电压工作至关重要）是这一页的核心。

为什么“低电压”尤其危险？因为电源电压降低时，VT 不能等比例降低（否则漏电爆炸），于是过驱动电压 VGT = VDD − VT 被压缩得越来越小，速度急剧下降。这就是所谓的电压缩放墙（voltage scaling wall）：VDD 从 5 V 降到 1 V 很容易，再往下就难了。

8.3 DIBL：漏压也能“开门”

这是短沟道器件最重要、也最容易被忽略的效应之一（PPT 未讲，属于补充）：

沟道很短时，漏极的电场会“越过”沟道，直接把源端的势垒拉低——相当于漏压也在帮忙“开门”。结果是阈值电压随 VDS 增大而下降：

VT(VDS) = VT0 − η VDS(3-39)

η（DIBL 系数）典型 0.05~0.15。它的危害很直接：

• 关态漏电随 VDS 增大而增大：待机时 VDS = VDD 最大，漏电也最大；

• 输出电阻降低：饱和区电流随 VDS 上升更快，等效于 λ 变大；

• 器件一致性变差：不同位置的 VDS 不同，VT 就不同。

DIBL 是 FinFET/GAA 等三维结构要解决的核心问题（§9）——栅极包得越严实，漏极越难“越界”。

8.4 迁移率退化

纵向栅压很大时，载流子被紧紧压在硅/氧化层界面上，界面粗糙度和散射急剧增加，迁移率下降。经验公式：

μeff = μ0 / (1 + θ(VGS − VT))(3-40)

后果：VGS 很大时，电流不再按平方律增长，增长变慢。这解释了为什么 §4 的短沟道例题用统一模型算出的 509 μA 仍比实测偏高——真实器件还有这一项没算。它也解释了为什么“拼命提高 VGS”并不能无限提高驱动能力。

8.5 电荷共享与 VT roll-off

长沟道模型假设“栅极下面的耗尽层电荷全部由栅极控制”。但沟道很短时，源、漏自己的耗尽区也占据了沟道下方一部分电荷，栅极“管不到”这些电荷，于是达到反型所需的栅压变小——VT 随 L 减小而下降，称为VT roll-off。

这是器件缩小过程中的一个基本矛盾：L 越小，VT 越难控制，而且不同 L 的管子 VT 不同，给设计带来麻烦（所以标准单元库只用少数几种 L）。

8.6 闩锁（Latch-up）：CMOS 的“内伤”

这是 PPT 唯一点名的可靠性问题，也是 CMOS 工艺最经典的“坑”。它和 §1.7 讲的寄生二极管是同一件事的延伸。

图 8-2　CMOS 中的寄生 NPN/PNP 结构与等效电路（PPT 第 43 页）

结构上怎么来的？ 在 p 衬底 + n 阱的 CMOS 里，天然形成了两个寄生双极晶体管：

• 横向 PNP：PMOS 的 p⁺ 源（发射极）+ n 阱（基极）+ p 衬底（集电极）；

• 纵向 NPN：NMOS 的 n⁺ 源（发射极）+ p 衬底（基极）+ n 阱（集电极）。

注意它们首尾相接：PNP 的集电极是 NPN 的基极，NPN 的集电极又是 PNP 的基极。于是形成一个可控硅（晶闸管，thyristor）结构——一旦触发，就会自己维持导通，这就是闩锁。

正反馈是怎么发生的？ PPT 用一句话概括：“PNP 微导通 → NPN 基极，导通 → PNP 基极，加剧导通”。展开来说：

① 某个扰动（ESD、输入过冲/下冲、电源上电顺序、辐射粒子）让 p 衬底里出现电流，衬底电阻 Rpsubs 上产生压降，把 NPN 的基极-发射极正偏；

② NPN 导通，从 n 阱抽走电流，n 阱电阻 Rnwell 上产生压降，把 PNP 的基极-发射极正偏；

③ PNP 导通，又向 p 衬底注入电流，回到第 ① 步——环路增益 > 1 时，电流越滚越大；

④ 最终 VDD 与 GND 之间被一条低阻通路短路，电流可达安培级，芯片局部烧毁（而且断电才能恢复，因为它是自锁的）。

8.7 其它漏电来源：GIDL 与结漏电

除了亚阈值漏电，还有两条漏电通道（补充内容，考试偶尔考概念）：

• GIDL（栅致漏极泄漏，Gate-Induced Drain Leakage）：当 VGS 很负、VDS 很高时（对 NMOS 就是关断且输出为高），漏极下方的能带被拉得很弯，发生带间隧穿，产生漏电。它在关态最严重，是低功耗设计的大敌。

• 结漏电（junction leakage）：反偏 PN 结的漏电流，包括少子扩散电流和耗尽区的产生-复合电流，与温度强相关（每升 10 ℃ 约翻倍）。这也是为什么高温下芯片更费电、更容易失效。

把三者加起来就是芯片的静态功耗：P_static = VDD × (I_sub + I_GIDL + I_junction)。在 90 nm 以下，这部分已经和动态功耗同一个量级，这就是为什么“低功耗设计”成了独立的研究方向。

9 新型器件：FinFET、GAA 与 CFET

PPT 最后一页只有几行字，但它指向了整个行业过去十年的技术主线。这一节把它讲清楚，让你知道“为什么 MOSFET 会变成现在这个样子”。

9.1 为什么要换结构

平面（planar）MOS 管的根本问题是：栅极只从上面“压”住沟道一面，对沟道的控制力有限。当 L 缩短到 20 nm 量级时：

• 漏极电场很容易“越过”沟道，把源端势垒拉低 → DIBL 严重、关不断；

• 为了抑制短沟道效应，沟道要做得很薄、掺杂要很高，但这又让迁移率下降、VT 波动变大；

• 栅氧已经薄到 1 nm 量级，隧穿漏电无法忍受。

解决思路很直接：让栅极把沟道“包”起来，包得越多，控制力越强，短沟道效应越弱。这就有了 FinFET → GAA → CFET 的演进路线。

9.2 FinFET：把沟道立起来

FinFET（鳍式场效应晶体管） 把沟道做成一片“竖起来的薄片”（像鱼鳍），栅极从左、右、上三个方向包住它。

9.3 GAA：四面都包住

GAA（Gate All Around，全环绕栅极） 进一步把沟道做成一根（或多根）悬空的“纳米片/纳米线”，栅极从四个方向全部包住。

• 适用节点：5 nm 及以下（三星 3 nm、台积电 2 nm 开始用）。

• 优点：静电控制最强，短沟道效应几乎被压制住；沟道宽度可以通过“纳米片的宽度”连续调节，缓解了 FinFET 的宽度量化问题。

• 难点：工艺复杂（需要反复外延/刻蚀/释放），成本高；寄生电容和自热问题更突出。

9.4 Forksheet 与 CFET：继续往上叠

图 9-1　CMOS 器件结构的演进路线：FinFET → Nanosheet → Forksheet → CFET（PPT 第 46 页，数据来自 2020 Symposia on VLSI Technology）

PPT 这张图来自 imec 的路线图，讲的是“怎么在同样的面积里塞进更多性能”：

• FinFET（N3 节点，即 3 nm 级）：标准的三面栅，单元高度 6T、2 个 fin。

• Nanosheet（N2，2 nm 级）：纳米片 GAA，单元高度 5T、1 个纳米片。

• Forksheet（N1 前）：在 n 型和 p 型器件之间插入一层“介质墙”（forksheet），让 N/P 间距进一步缩小，单元高度降到 4.3T 左右。

• CFET（Complementary FET）：把 NMOS 直接叠在 PMOS 上面（三维堆叠），单元高度降到 4T/3T，是路线图的下一站。

PP、MP、T 这些缩写分别是“ contacted poly pitch（接触栅间距）”、“metal pitch（金属间距）”和“track（单元高度单位）”——它们是衡量工艺密度的行业黑话，这里知道意思即可。

9.5 这些变化对“学器件”意味着什么

好消息是：前面七节的物理图像全部仍然成立——阈值、反型、I–V、电容，只是几何形状变了（W 的计算方式变了、栅极包裹方向变了）。

坏消息是：定量公式需要修正。比如 FinFET 的 W 是“2Hfin + Tfin”而不是版图上的宽度；亚阈值斜率因为控制力变强而更接近 60 mV/dec；DIBL 明显减小；但寄生电容、自热、变异性的问题反而更复杂。

【一句话记住】

器件演进的唯一主线：让栅极把沟道包得更严实。 三面（FinFET）→ 四面（GAA）→ 上下叠（CFET）。理解这条线，你就理解了为什么工艺要这么走。

10.2 十条核心结论

① MOS 是电压控制的开关：栅压通过电容感应出沟道电荷，栅极几乎不流电流，这是 CMOS 低功耗的根源。

② VT 是开关的门槛，它由功函数差、表面势、耗尽层电荷、氧化层电荷和沟道注入共同决定，并且随体偏置（体效应）和温度变化。

③ 过驱动电压 VGT = VGS − VT 才是驱动电流的量，所有“为什么变快/变慢”的问题都能从这里找到答案。

④ 三个工作区：截止（开关断开）、线性（压控电阻）、饱和（压控电流源）。判断顺序：先 VGT，再比 VDS 与 VGT。

⑤ 长沟道是平方律，短沟道是“提前饱和 + 近似线性”。0.25 μm 以下必须用 Vmin 统一模型，否则会高估电流约一倍。

⑥ L 是工艺给的，W 是设计者唯一的旋钮。加大 W 提高驱动，但要付出电容和功耗。

⑦ 栅电容随工作区重新分配（截止全给体、线性各一半、饱和 ⅔ 给源），但总量基本是 Cox·W·Leff；结电容按“面积 + 周长”算，和工作区无关。

⑧ Req 是把非线性器件压成一个电阻的工程手段，Req ≈ 0.75VDD/IDSAT，用来做 RC 延迟估算。

⑨ 关断不等于零电流：亚阈值电流指数变化，S ≈ 60~100 mV/dec，它决定了待机功耗，也决定了 VT 不能随便降。

⑩ 器件演进的唯一主线是让栅极包得更严实：平面 → FinFET → GAA → CFET，目的是压住短沟道效应。

4. VS = 0.8 V，VB = 0，VSB = 0.8 V（反偏）：VT = 0.43 + 0.4(√(0.6+0.8) − √0.6) = 0.43 + 0.4(1.183 − 0.775) ≈ 0.593 V。

5. VGT = 2.5 − 0.593 = 1.907 V。VDS = 0.3 V < VGT，所以在线性区：ID = 115×10⁻⁶×4×[1.907×0.3 − 0.09/2] = 460×10⁻⁶×(0.572−0.045) ≈ 242 μA。

6. 长沟道：ID = 0.5×115×10⁻⁶×4×1.907² ≈ 836 μA（未计 λ）。统一模型：Vmin = min(1.907, 2.5, 0.63) = 0.63 V，ID = 460×10⁻⁶×(1.907×0.63 − 0.63²/2) ≈ 460×10⁻⁶×1.003 ≈ 461 μA。长沟道公式高估了约 81%，所以短沟道必须用统一模型。

7. W/L = 8。饱和区：CGS = ⅔×6×2×0.25 = 2.0 fF；覆盖电容两侧各 Co·W = 0.31×2 = 0.62 fF；Cgate ≈ 2.0 + 0.62 + 0.62 ≈ 3.24 fF。

8. Cdiff = 2×0.6×2 + 0.28×(1.2+2) = 2.4 + 0.896 ≈ 3.30 fF。

9. ΔVT = 0.1 V，倍数 = 10^(100/75) = 10^1.333 ≈ 21.5，所以漏电 ≈ 5 nA × 21.5 ≈ 108 nA（涨了 21 倍）。

10. Req ≈ 0.75×2.5/(1×10⁻³)×(1 − (5/6)×0.06×2.5) = 1875×0.875 ≈ 1.64 kΩ；延迟 ≈ 0.69×1.64kΩ×20 fF ≈ 22.6 ps。

11. 三个原因：① 串联使等效电阻加倍；② 上面那个管子的源电位不是 0，VSB > 0，体效应使它的 VT 变大、电流变小；③ 中间节点还有电容，翻转时要先给它充放电。三者叠加，使串联链的电流只有单管的 1/2~1/3，这就是为什么宽门（如 4 输入与非）的下拉要做得更宽。

12. 让 IDSAT 相等：½kn′(W/L)n·VGTn² = ½kp′(W/L)p·VGTp²。若 |VTp| = 0.4 V、VDD = 2.5 V，则 VGTn = 2.07 V、VGTp = 2.1 V，几乎相等，所以 (W/L)p ≈ (kn′/kp′)(W/L)n ≈ (115/30)×4 ≈ 15.3，即 Wp/L ≈ 15.3。这解释了那条经验法则：PMOS 要比 NMOS 宽 2~4 倍（这里 3.8 倍）。

A.3 下一步学什么
