0 导学：为什么先学反相器

数字电路里有几百种门，但只有一种电路值得从头到尾彻底分析——反相器。原因有三：

① 它是最小的逻辑门：一个 PMOS 加一个 NMOS，就把“非”实现了；

② 其他门都是它的变形：与非门 = 反相器 + 串联 NMOS + 并联 PMOS；或非门、与或非门同理；

③ 所有关键指标都在它身上定义：逻辑电平（VOH/VOL）、噪声容限（NMH/NML）、开关阈值（VM）、延迟（tp）、功耗（P）。后面分析任何门，用的都是这一套语言。

本章的逻辑主线是四步：

结构 → 直流特性（VTC、噪声容限）→ 动态特性（延迟）→ 功耗与尺寸设计

这四步走完，你就有了评价“一个门好不好”的完整工具箱。

1 结构、版图与“无比逻辑”

1.1 电路：两个管子，一个输入一个输出

CMOS 反相器（inverter）的电路简单到不能再简单：PMOS 在上（接 VDD），NMOS 在下（接地），两个栅极连在一起做输入，两个漏极连在一起做输出。

为什么这么接就能实现“非”？记住第 3 章的两条：

• 输入为 0（VIN = 0）：NMOS 的 VGS = 0 < VTN，截止；PMOS 的 VSG = VDD > |VTP|，导通 → 输出被上拉到 VDD → 输出 1。

• 输入为 1（VIN = VDD）：NMOS 的 VGS = VDD > VTN，导通；PMOS 的 VSG = 0，截止 → 输出被下拉到 0 → 输出 0。

关键点：任何时刻两个管子只有一个导通（稳态时），所以 VDD 到 GND 之间没有直流通路——这就是 CMOS 静态功耗极低的根本原因。

PPT 第 2 页把 CMOS 电路的优点总结了五条，值得逐条理解：

“无比逻辑”到底是什么意思

早期的 NMOS 逻辑（如 E/D NMOS）靠电阻分压决定输出高电平：输出高电平= VDD × R_load/(R_driver + R_load)，于是“1”到底是多少伏，取决于两个管子的尺寸比。

CMOS 是无比逻辑（ratio-less logic）：输出高电平由导通的 PMOS 直接短接到 VDD，与 W/L 无关。所以你可以为了速度任意调整 Wp/Wn，而不用担心逻辑电平跑掉。这是 CMOS 取代 NMOS 的关键优势之一。

1.2 版图与剖面：每个细节都有原因

图 1-1　CMOS 反相器的版图（上）与剖面（下）：左边 NMOS 坐在 p 衬底上，右边 PMOS 坐在 n 阱里，一条多晶硅同时跨过两个有源区形成两个栅（PPT 第 3 页）

这张图信息量很大，逐个看：

• 一条多晶硅（红色斜线）横跨两个有源区，形成两个栅极；它的左端是输入 A，中间向下引出的金属是输出 Y。这就是“两栅相连”。

• 左边绿色是 NMOS 有源区（NAA），源漏是 n⁺；右边橙色是 PMOS 有源区（PAA），外面套了一圈 n 阱（n well），源漏是 p⁺。

• 黑色方块是接触孔（contact）：把金属连到有源区或多晶硅上。注意输出 Y 的金属同时接到两个漏区，这就是“两漏相连”。

• 衬底接触（substrate tap）接 GND、阱接触（well tap）接 VDD：这是第 3 章 §1.7 讲过的——保证所有 PN 结反偏、防止闩锁。版图上那些“看起来多余的小方块”，就是干这个的。

• 剖面图里能看到：栅氧很薄（在 poly 下面），其余地方是厚厚的场氧（FOX），用来隔离相邻器件。

版图上写的 2λ 是“最小设计规则单位”：所有尺寸都是 λ 的整数倍，这样工艺缩放时版图可以整体等比缩小。

2 再生特性：数字电路为什么能“洗干净”信号

这是本章第一个、也最容易被跳过的重要概念。它回答一个根本问题：为什么数字电路可以一级一级传下去，而噪声不会累积到无法区分？

2.1 从一条反相器链说起

图 2-1　反相器链：输入的小摆幅信号被逐级放大到满幅（上图）；如果门是“非再生”的，摆幅会逐级衰减直至消失（下图）（PPT 第 5 页）

假设第一级的输入是一个“不干净”的电平（比如 0.7 V 而不是 0 V）。如果这个门的电压传输特性（VTC）足够陡，输出会被“拉”到接近 0 或 VDD；下一级再拉一次，几次之后信号就变成干净的高低电平。这个过程叫再生（regeneration），是数字电路抗噪声的根本机制。

反过来，如果 VTC 不够陡（增益 < 1），每过一级摆幅都会缩小，几级之后信号就淹没在噪声里——这样的门不能用来做数字电路。

把输出电压对输入电压作图，就得到电压传输特性（VTC，Voltage Transfer Characteristic）。一个合格的反相器，VTC 必须有三段：

2.3 收敛点：V_OL 与 V_OH 的严格定义

图 2-2　把 VTC 和它的反函数画在一起：三个交点分别是两个稳定收敛点（V_OL,V_OH）和（V_OH,V_OL），以及一个不稳定点 VM（PPT 第 9 页）

把 VTC 记作 Vout = f(Vin)，再画出它的反函数 Vin = f⁻¹(Vout)（其实就是把曲线沿对角线翻折）。两条曲线的交点满足 Vout = f(Vin) 且 Vin = f(Vout)，也就是“输出接回输入后能自我保持”的状态。

这样的交点有三个：

① （V_OL, V_OH）：输入低、输出高，稳定；

② （V_OH, V_OL）：输入高、输出低，稳定；

③ （VM, VM）：输入输出相等，不稳定（亚稳态）。

所以数字电平不是“设计者规定的”，而是电路自己收敛出来的两个吸引子。这也解释了 §2.4 的一个漂亮实验。

第三种方法特别值得记住，因为它只用“连接方式”就能区分稳定与不稳定：两个反相器首尾相接 = 正反馈 = 双稳态 = 静态存储器（SRAM）的基本单元；一个反相器首尾相接 = 负反馈 = 稳定在 VM = 可以测出开关阈值。

PPT 第 13 页：两个反相器首尾相接，为什么就是 SRAM？

首尾相接后形成正反馈环：若节点 A 为高，则 B 为低，B 低又反过来维持 A 高。两个状态（A 高 B 低 / A 低 B 高）都是稳定的，所以能存住 1 bit；只要不断电，状态就一直保持——这正是 SRAM 的存储原理。

而一个反相器首尾相接是负反馈：任何偏离都会被拉回 VM，所以它稳定在中间电平，既不是 0 也不是 1，不能存储。

2.5 VM 为什么不能当判决阈值

VM 是 VTC 与对角线 Vout = Vin 的交点，也叫开关阈值（switching threshold），它表征 VTC 的对称性：VM = VDD/2 说明上升沿和下降沿对称。

但 VM 不是数字量的判决阈值！原因很直接：输入停在 VM 附近时，输出也停在 VM 附近，此时任何微小干扰都会让输出随机偏向 0 或 1——没有任何噪声容限。所以真实的判决阈值是两个“斜率 −1”点之间的一段区域，而不是一个点（§3 会定义 V_IL 和 V_IH）。

3 静态特性（一）：VTC、V_IL/V_IH 与噪声容限

3.1 VTC 是怎么算出来的

反相器的输出节点没有直流通路（除非两管同时导通），所以稳态时流过 NMOS 的电流必须等于流过 PMOS 的电流（方向相反）：

IDSN(VIN, VOUT) + IDSP(VIN, VOUT) = 0(5-1)

给定一个 VIN，解这个方程就能得到唯一的 VOUT——把所有 VIN 扫一遍，就是 VTC。PPT 第 15 页把两个管子的统一模型直接相加，写成了：

kn'(W/L)n(VGTNVmin − Vmin2/2)(1+λVDS) + (PMOS 同理) = 0(5-2)

这个式子是“分段”的：随着 VIN 从 0 扫到 VDD，NMOS 和 PMOS 会依次经历截止、饱和、线性三种状态，所以 VTC 要分五个区分别求解。 （下一节用负载线把这件事画出来。）

3.2 V_IL 与 V_IH：用“斜率 −1”定义

图 3-1　用 |dVout/dVin| = 1 的两个点定义 V_IL 和 V_IH，从而把模拟电压划成“0 区 / 未定义区 / 1 区”（PPT 第 17 页）

VTC 上增益等于 −1 的两个点，把输入电压分成三段：

• VIN < V_IL：输出稳定在高电平，这一段叫“0 区”（输入 0 是可靠的）；

• V_IL < VIN < V_IH：过渡区，输出对输入极其敏感，逻辑上“未定义”；

• VIN > V_IH：输出稳定在低电平，“1 区”。

为什么用斜率 −1 来定义？因为增益为 1 是“放大”与“衰减”的分界：在 |增益| > 1 的区域，输入的任何小变化都会被放大成输出的巨大变化，信号不可靠；在 |增益| < 1 的区域，输出是“钝”的，可靠。

3.3 噪声容限：数字电路的安全边际

图 3-2　噪声容限的定义：NMH = VOH − VIH，NML = VIL − VOL（PPT 第 18 页）

噪声容限（noise margin）回答的问题是：输入端最多能承受多大的干扰，还不至于误判？ 定义非常直观：

NMH = VOH − VIH(5-3)
NML = VIL − VOL(5-4)

高电平噪声容限 NMH：前一级给出的“1”最低是 VOH，后一级能认作“1”的最低是 VIH，两者之差就是“1”可以跌落的余量。低电平噪声容限 NML 同理。

题：VDD = 1.5 V，VOH = 1.35 V，VOL = 0.2 V，VIH = 1.2 V，VIL = 0.3 V。求 NMH 与 NML。（PPT 第 19 页原题）

解：直接代公式——

NMH = 1.35 − 1.2 = 0.15 V

NML = 0.3 − 0.2 = 0.1 V

解读：两个容限都不大（只有 0.1~0.15 V，约 7%~10% VDD），说明这个反相器的 VTC 不够陡、或者输出摆幅有损失。理想 CMOS 反相器的 NM 可以到 0.4 VDD 左右。

PPT 第 21 页讲噪声预算（noise budget）：总的噪声容限要分配给各个噪声源（电源噪声、串扰、干扰、漂移……）。这里有一个很重要的观点：

【一句话记住】

噪声分“外部”和“内部”。对内部噪声（与信号成比例的，比如串扰），单纯加大信号摆幅是没用的——因为噪声也同比变大。

所以提高抗噪声能力要靠：更陡的 VTC（更大增益）、更低的输出阻抗、更高的输入阻抗、更好的电源/地网络，而不是一味提高 VDD。

请注意最后一行：恒定电场缩放时，功率密度保持不变。 这意味着：芯片越做越密、越快，但单位面积发热量一点都不降——散热成了瓶颈。而在“恒定电压”缩放下，功率密度还会上升。这就是 2000 年代之后主频停在 3~4 GHz 附近（“功耗墙”）的根本原因。

PPT 第 65~70 页还给了一组很有说服力的趋势数据：

• 特征尺寸：从 1960 年代的 ~30 μm 降到 2010 年的 ~0.02 μm（指数下降）；

• 门延迟：每年减少约 13%，每五年减少一半；

• 晶体管数：每 1.96 年翻一番（Moore 定律的原始表述）；

• 微处理器功耗：每年翻一番（这才是真正的问题）；

• 每代收益（尺寸减 30%）：门延迟降 30%、频率升 43%、密度翻倍、每次转换能耗降 65%。

但 PPT 也在第 73、74 页的表格下面写了两条警告：“亚阈值电流（静态功耗）指数增加”、“亚动态功耗增加”。换句话说：等比例缩小让动态功耗下降了，却让漏电指数上升——这就是第 3 章 §8 讲的亚阈值问题，在系统层面的总爆发。

9 尺寸设计：从单位反相器到反相器链

9.1 单位反相器与本征/外部负载

为了做定量设计，先定义一个单位反相器（unit inverter）：L 取最小尺寸，NMOS 宽度为 Wo，PMOS 宽度为 βWo（β ≈ 3.5，保证对称），它的输入电容记为 Cgino。

一个门的负载电容分两部分（PPT 第 75 页）：

CL = Cint + Cext(5-5)

• 本征电容 Cint：管子自己的漏结电容、栅漏覆盖电容等（2Cgd12 + Cdb2 + Cdb1）；

• 外部电容 Cext：后级的栅电容 Cg3、Cg4 以及连线电容 Cw。

定义 Cint = γ·Cgino（γ 约等于 1），并把单位反相器的空载延迟记作 Tp0。把一个反相器放大 s 倍（所有宽度乘 s），则：

Rn(s) = Rp(s) = Ro/s, Cgin(s) = s·Cgino, Cint(s) = s·Cinto(5-6)

注意：放大 s 倍后，电阻降为 1/s、电容升为 s 倍，所以空载延迟 Tp0 不变。 尺寸本身并不能让门更快，它只能让门“带得动更大的负载”。

9.2 延迟公式：Tp = Tp0 (1 + f/γ)

让尺寸为 s1 的反相器驱动尺寸为 s2 的反相器，则负载是 s2·Cgino，代入 RC 公式：

tp ≈ (Ro/s1)(s1Cinto + s2Cgino) = Tp0[1 + (s2/s1)/γ](5-7)
tp = Tp0(1 + f/γ), f = s2/s1 = Cext/Cgin(5-8)

其中 f 叫有效扇出（effective fanout）= 负载电容 / 本级输入电容。这个公式是本章最有用的设计公式，它说：

• Tp0 是“底噪”：由工艺和版图决定，与尺寸无关；

• f 是“代价”：扇出越大，延迟越大，而且近似线性增加；

• 要减小 f，要么减小负载（缩短线、减小后级尺寸），要么加大本级尺寸。

9.3 最优 P/N 比：k = √β

前面为了让上升沿和下降沿对称，取 Wp/Wn = β ≈ 3.5。但 PPT 第 81、82 页指出：如果追求的是“平均延迟最小”，而不是“完全对称”，最优的 P/N 比其实是 √β ≈ 2。

推导思路：设 Wp = k·Wn。k 越小，PMOS 越弱，上升沿越慢（tpLH 变大）；但 PMOS 越小，输入电容越小（(1+k) 变小），下拉延迟 tpHL 变小。两者相加再对 k 求极值，得到 k = √β。

tp ≥ Tp0[1/2 + √β/(1 + β)], 当 k = √β 时取等号(5-9)

PPT 的结论：k = √β ≈ 2 时，平均延迟比 β = 3.5 时减小约 10%，面积和功耗也略小；代价是上升/下降沿不对称。所以“对称”与“最快”是两个目标，标准单元库通常选取折中值。

10.2 八条核心结论

① 反相器 = 上拉 PMOS + 下拉 NMOS，稳态只有一个导通，所以静态功耗极低、输出满摆幅。

② 再生特性（过渡区增益 > 1）是数字电路能“洗干净信号”的根本，它的数学体现就是 VTC 的三个交点。

③ VTC 分五区：截止/饱和/线性组合决定形状；第 ③ 区（两管都饱和）最陡、增益最大（0.25 μm 约 −17）。

④ VM 只由尺寸比决定；对称设计取 Wp/Wn ≈ kn′VDSATn/(kp′VDSATp) ≈ 2.4；追求最快则取 √β ≈ 2。

⑤ 噪声容限由 VTC 的陡度决定，理想是 VDD/2，实际约 0.4VDD。

⑥ 延迟 = 0.69ReqCL，依赖 CL、VDD、W/L、工艺四项；增大 W 有效，但会让前级变慢（自载）。

⑦ 动态功耗 = αCVDD²f，每次翻转消耗 CVDD²（一半发热）；短路功耗只在翻转瞬间产生，正常设计 <10%。

⑧ 驱动大负载要用反相器链，每级扇出 3~4，延迟从 ∝F 变成 ∝logF。

11 自测题（含详解）

1. 为什么 CMOS 反相器的输出高电平总是 VDD（与 Wp/Wn 无关）？

2. 一个反相器 VDD = 2.5 V，VOH = 2.5 V，VOL = 0，VIH = 1.9 V，VIL = 0.6 V。求 NMH、NML，并判断它是否对称。

3. 已知 kn′ = 115 μA/V²、kp′ = 30 μA/V²、VDSATn = 0.63 V、VDSATp = −1 V。求使 VM = VDD/2 的 Wp/Wn。

4. 用 0.25 μm 参数（Req,n = 13 kΩ @ VDD = 2.5 V，W/L = 1），求 W/L = 4 的 NMOS 驱动 CL = 20 fF 的 tpHL。

5. 一个节点电容 50 fF、VDD = 2.5 V、每秒翻转 10⁸ 次（α = 0.2）。求动态功耗。若 VDD 降到 1.5 V，功耗变成多少？

6. 环形振荡器由 11 级反相器组成，测得周期 1.1 ns。求单级延迟。

7. 要驱动 F = 1000 倍的单位负载，用最优反相器链，级数和每级扇出是多少？延迟约多少个 Tp0？

8. 为什么“把管子加宽一倍”不能让空载延迟减半？

参考答案

1. 因为输出为高时，导通的 PMOS 把输出直接短接到 VDD（相当于一个电阻接到电源），而不是靠两个管子分压。所以电平由电源决定，与尺寸无关——这就是“无比逻辑”。

2. NMH = 2.5 − 1.9 = 0.6 V；NML = 0.6 − 0 = 0.6 V。两者相等 → 对称；且 0.6/2.5 = 24%，远小于理想的 50%，说明 VTC 过渡区偏宽。

3. Wp/Wn = kn′VDSATn/(kp′|VDSATp|) = (115×0.63)/(30×1.0) ≈ 2.4。

4. Req = 13 kΩ / 4 = 3.25 kΩ；tpHL = 0.69 × 3.25k × 20f ≈ 45 ps。

5. P = αCVDD²f = 0.2 × 50f × 2.5² × 10⁸ ≈ 6.25 μW；VDD = 1.5 V 时 P ∝ VDD² → 6.25 × (1.5/2.5)² ≈ 2.25 μW（降 64%）。

6. tp = T/(2N) = 1.1 ns/22 = 50 ps。

7. f = F^(1/N)，取 f ≈ 4 → N = log₄1000 ≈ 5 级；延迟 ≈ N·Tp0(1+f/γ) ≈ 5×Tp0×5 ≈ 25 Tp0（与表 5-14 的 24.8 一致）。

8. 因为加宽一倍后，电阻减半但本征电容也加倍，两者的乘积不变，所以空载延迟 Tp0 不变。加宽只对“驱动外部大负载”有帮助（把外部负载摊薄）。
