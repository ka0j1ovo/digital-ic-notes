0 导学：组合逻辑的四种实现与评价

组合逻辑（combinational logic）的定义是：输出只取决于当前的输入，没有记忆。它和时序逻辑（第 7 章）的区别就在“有没有记忆”。

评价一个组合门，永远看四个指标：面积、速度、能量/功率、稳定性（鲁棒性）。 四者互相矛盾，所以“最优实现”取决于应用场景：高性能 CPU 偏爱动态逻辑，低功耗 SoC 偏爱静态 CMOS，面积敏感的存储器外围偏爱传输门。

1 静态互补 CMOS：把逻辑式直接“翻译”成电路

1.1 开关的串并联就是“与/或”

先建立最基本的直觉（PPT 第 7 页）：把 MOS 管看成理想开关。

• NMOS：栅为 1 时导通（同相开关）；PMOS：栅为 0 时导通（反相开关）。

• 串联 = 与：所有开关都闭合才通；并联 = 或：任一闭合就通。

于是任意“与/或”表达式都能搭出来：F = A·(B+C) 就是“A 与 (B 或 C)”——先把 B、C 并联，再与 A 串联。

1.2 互补网络的“取反”规则

静态互补 CMOS 的结构固定：上拉网络 PUN（全 PMOS）接 VDD，下拉网络 PDN（全 NMOS）接地，输出在中间。它的逻辑关系是一个漂亮的对称：

OUT = ¬G(In1, In2, …) = ¬F(In1, In2, …)(6-1)

其中 G 是 PDN 的导通条件、F 是 PUN 的导通条件，且两者互为对偶（串联↔并联、原变量↔反变量）。给一个例子就明白了：

第二步画 PDN：最外层是“或”，所以 D 与 A·(B+C) 这条支路并联；支路内部 A 与 (B+C) 串联；B、C 之间并联。

第三步画 PUN（对偶）：D 与支路串联；A 与 (B+C) 的并联组并联；B、C 之间串联。

第四步检查：A、B、C、D 每个输入都恰好接一个 NMOS 和一个 PMOS；任何输入组合下 PUN 与 PDN 恰好一个导通——满足互补性。

1.3 为什么必须“严格互补”

PPT 第 10 页强调：互补意味着任何输入组合下，PUN 与 PDN 恰好一个导通。两种违例都会出问题：

• 两个都导通：VDD 到 GND 直通，输出停在中间电平（既不是 0 也不是 1），还有大静态电流——绝对禁止；

• 两个都不导通：输出浮空（高阻），电平由电荷和漏电决定，这是三态门才允许的状态。

所以“互补”不是可选项，而是静态 CMOS 的正确性前提。

1.4 单级只能反相：与门要两级

静态互补 CMOS 的单级门天生带“非”：NAND、NOR、AOI 都是反相输出。 要做“与”或“或”，必须再加一级反相器：AND = NAND + INV，OR = NOR + INV。这带来两个代价：多一级延迟、多一倍面积。

这也解释了为什么标准单元库里与非门比与门多、或非门比或门多——设计者尽量用“反相逻辑”来省一级门。

2 版图与标准单元

2.1 棒图：版图的“草图”

PPT 第 19~23 页用棒图（stick diagram）讲版图：只用线条表示各层的相对位置，不画具体尺寸。四个要点：

① 各管共享有源区：相邻的源或漏合并，节省面积；

② 栅极用一条多晶硅贯通：输入 A、B 就是两条竖直的 poly；

③ 注入区尽量连续：断开的地方要用金属跳线，浪费面积；

④ 尽量只用 metal1：用 metal2 会占用布线资源。

以 2 输入与非门为例：PMOS 两管并联（S 接 VDD、D 共接 Out），NMOS 两管串联（B 在上、A 在下，S 接地），输出在中点——版图上就是 4 条 poly、中间一个公共漏、上下两条电源轨。

3 静态特性：为什么与非门比或非门好

3.1 VTC 与输入模式有关

反相器只有一个输入，VTC 是一条曲线；而多输入门的 VTC 取决于哪个输入在变（PPT 第 25 页）。以二输入与非门为例：

• A 从 0 变 1（B = 1）：只有 A 这一个 NMOS 在切换，另一个已经导通；

• B 从 0 变 1（A = 1）：同理；

• A、B 同时从 0 变 1：两个管子同时切换，翻转点最陡、最快。

另一个效应是体偏置：串联的 NMOS 里，上面那个管子的源不是地，而是中间节点，VSB > 0 → VT 变大（第 3 章 §2.5 的体效应）。所以串联链越深，上面的管子越弱——这就是扇入越大越慢的原因之一。

3.2 扇入的代价：平方律恶化

PPT 第 35、36 页用 Elmore 公式算了一个 4 输入与非门的最坏延迟：

tpHL = rCi + 2rCi + 3rCi + 4CL = 4rCL + 6rCi(6-2)

其中 r 是每个串联管的电阻，Ci 是每个中间节点的电容。可以看出：n 个管子串联时，延迟里出现了 1+2+…+n = n(n+1)/2 这一项——这就是“扇入越大越慢，而且是平方关系”的来源。

图 3-1　4 输入与非门的最坏延迟：4 个 NMOS 串联，中间节点电容被逐级充放，延迟出现 n(n+1)/2 的平方项（PPT 第 35 页）

而上拉是并联的，延迟只随扇入线性增加：

tpLH = 0.69Reqp(Cint + CL)(6-3)

所以对同一个 n 输入门：与非门的慢路径是“n 个 NMOS 串联”（平方恶化），或非门的慢路径是“n 个 PMOS 串联”（也是平方恶化，但 PMOS 本来就弱 3 倍）。 两者一比，或非门比与非门差得多——这就是标准单元库里 NAND 用得远比 NOR 多的原因。

【一句话记住】

同样的扇入，NAND 优于 NOR。 所以综合工具会尽量把逻辑“推”成与非/与或非形式；写 RTL 时如果能让“或”少一点，时序会好做很多。

3.3 扇入与扇出的统一模型

PPT 第 37 页把两个效应合起来写成：

tp = a1·FI + a2·FI2 + a3·FO(6-4)

FI 是扇入（fan-in），FO 是扇出（fan-out）。扇入既有线性项又有平方项（因为串联既有电阻也有中间电容），扇出只有线性项（每多一个负载，就多两个栅电容：一个 NMOS + 一个 PMOS）。

4 尺寸规划：让每个门“刚好够劲”

4.1 从反相器到与非门：尺寸怎么定

设单位反相器是 NMOS W = 1、PMOS W = 2（比例 2:1，为对称）。做 n 输入门时，原则是保证最坏情况的驱动能力与反相器相当：

• 并联时尺寸保持：并联电阻本来就小，最坏情况是“只有一个管子跳变”，所以每个管子都按单位尺寸做；

• 串联时尺寸加倍：n 个管子串联，电阻变成 n 倍，所以每个管子宽度要乘 n。

4.2 复杂门：把最慢的输入放在“离输出最近”的位置

以 Y = ¬(A·B·C) 为例，三个 NMOS 串联。哪个输入应该放在最下面（靠近输出）？PPT 第 39 页给的规则是：速度快（关键路径上）的输入靠近输出。

原因：靠近输出的管子，它的源是地，没有体效应，而且放电时只需搬走 CL 的电荷；而靠近 VDD 的管子要“顶着”中间节点的电容。所以把关键信号放在最下面，可以少充放几个中间节点。

4.3 扇入太大怎么办：拆分级数或插缓冲器

对 8 输入 NAND（8 个 NMOS 串联）这样的门，延迟会非常差。三种优化：

① 拆成树形：8 输入 NAND + INV → 4 个 NAND2 → 2 个 NOR2 → NAND2 → INV，把“平方”拆成几段“线性”；

② 渐变尺寸（tapered sizing）：串联链里越靠近输出的管子做得越小，让 R1 < R2 < R3 < R4，平衡各节点的 RC；但版图上不好实现；

③ 插缓冲器：用小门实现逻辑，再用反相器链驱动大负载（第 5 章 §9.4）。PPT 算过：4 输入 NAND 加一级缓冲后，延迟里的电容项从 4Cint,ND4 + CL 变成 4Cint,ND4 + 7Cgin + CL——只要 CL 很大，插缓冲就划算。

5 有比逻辑：用电阻换管子

静态互补 CMOS 用了 2n 个管子，其中一半是 PMOS——而 PMOS 又慢又占面积。有比逻辑（ratioed logic）的想法是：用一个永远导通的负载（电阻或 PMOS）代替整个上拉网络，只用 n 个 NMOS 做逻辑。

5.2 输出低电平不再是 0：这就是“有比”的含义

当 PDN 导通时，上拉负载与 PDN 形成分压：

VOL = VDD · RPDN/(RPDN + RL)(6-5)

要 V_OL 足够低，必须 RL ≫ R_PDN，也就是上拉要“弱”、下拉要“强”——输出电压取决于两个管子的尺寸比，所以叫“有比逻辑”。（对比：静态 CMOS 是“无比逻辑”，电平与尺寸无关，见第 5 章 §1.1。）

由此带来三个后果：

• 静态功耗：PDN 导通时，VDD 到 GND 一直有电流（伪 NMOS 的经典问题）；

• 上升沿很慢：上拉是弱 PMOS，只能慢慢给 CL 充电（t_pLH = 0.69·RL·CL 很大）；

• VTC 不对称、对尺寸敏感：PMOS 稍微做强一点，V_OL 就抬高，噪声容限变差。

5.3 差分有比逻辑：DCVSL

为了去掉“分压”带来的摆幅损失，可以把有比逻辑做成差分：用两个互补的 PDN 分别拉两个输出，再用一对交叉耦合的 PMOS 做负载——这就是 PPT 第 49~52 页的 DCVSL（Differential Cascade Voltage Switch Logic）。

它的妙处：交叉耦合的 PMOS 形成正反馈，一旦一侧被拉低，另一侧的 PMOS 就被打开、把另一路拉到满幅 VDD。所以 DCVSL 既有有比逻辑的“管数少”，又恢复了满摆幅。代价是需要差分输入（A 和 ¬A 都要有），布线面积翻倍。

6.3 两个致命问题：漏电与电荷共享

① 漏电：求值阶段输出保持 1 时，输出节点是高阻的，亚阈值漏电会让电压慢慢往下掉。解决办法是加一个“弱维持器”（keeper）——一个栅接输出反相的弱 PMOS，负责把电荷补回来。代价是它会和 PDN “打架”，让放电变慢（所以要做得足够弱）。

② 电荷共享（charge sharing）：求值时如果 PDN 只导通了“部分路径”，输出电容 CL 上的电荷会分给内部节点 CA（PPT 第 61 页）：

ΔVout = −(CA/CL)[VDD − VTn(VX)](6-6)

如果 ΔV_out 太大，输出可能被误判成 0。解决办法：给内部节点也做预充（PPT 第 63 页的“内部节点预充”），或让关键内部节点常导通。

6.4 Domino：让动态逻辑能级联

动态门不能直接级联：因为求值阶段前一级可能“预充到 1 → 又放电到 0”，而后一级在同一个时钟里已经求值完毕，会漏掉这个跳变。Domino 逻辑的解决办法是：在动态门后面加一个静态反相器。

• 前一级动态门的输出只会 1 → 0（单调下降），经过反相器变成 0 → 1；

• 后一级在求值期只可能看到“0 → 1”的输入，正好符合“只能放一次电”的约束；

• 整个链像多米诺骨牌一样依次倒下——所以叫 Domino。

Domino 的代价：每级多一个反相器（面积、延迟）；而且只能实现非反相逻辑（因为输出已经反了两次）。要反相就得用“差分 Domino”（双轨，PPT 第 74 页）或 np-CMOS（第 75 页）。

np-CMOS：另一种级联方案

np-CMOS 用两类动态门交替：N 型（PDN + 时钟 NMOS）只做“1→0”的输出，P 型（PUN + 时钟 PMOS）只做“0→1”的输出。N 型驱动 P 型、P 型驱动 N 型，天然满足单调性，不需要额外的反相器。

代价：需要两套时钟（Clk 与 ¬Clk），而且 P 型门的 PMOS 网络本来就慢。所以 np-CMOS 用得不如 Domino 广。

7 传输管与传输门

7.1 用 NMOS 当开关：简单，但会“损失”电平

传输管逻辑（pass-transistor logic）直接把输入当开关用：一个 NMOS 的栅接控制信号，源接输入 A，漏接输出。它比 CMOS 省管子，但有三个先天缺陷（PPT 第 79、80 页）：

① 阈值损失：NMOS 传“1”时，输出最高只能到 Vgate − VT。因为当 Vout 升到 Vgate − VT 时，VGS = VT，管子就关断了。

② 电阻增大：随着 Vout 升高，VGS 变小，导通电阻变大，充电越来越慢。

③ 静态电流：如果后级是反相器，输入停在 VDD − VT 这种“中间电平”，会让后级的 PMOS 和 NMOS 同时微导通，产生静态电流。

所以“NMOS 传 1”是禁忌：它可以传“强 0”（0 V 能完整传过去），但传“1”会掉一个 VT。 PMOS 正好相反：传“强 1”、传“弱 0”（只能到 |VTP|）。

7.2 级联的灾难

如果把多个 NMOS 传输管串联（PPT 第 81、82 页），电平会一级一级往下掉：

VC = VD = … = VDD − VTn, 再串一级 → VDD − 2VTn, 再串 → VDD − 3VTn(6-7)

PPT 用红字写“绝对禁止”：一般要求 VDD ≈ 3~5 VT，否则串两级之后电平就掉到无法识别了。所以传输管不能长距离级联。

7.3 CMOS 传输门：NMOS 与 PMOS 并联

解决办法很优雅：把 NMOS 和 PMOS 并联，做成传输门（transmission gate，TG）。NMOS 擅长传 0、PMOS 擅长传 1，两者并联就“全都能传”：

7.4 实例：二选一与异或

二选一（MUX）：F = A·S + B·¬S。用两个传输门，S 选 A、¬S 选 B，输出并联即可——比用 CMOS 门实现省一半管子。

异或（XOR）：F = A⊕B。用传输门实现非常巧妙（PPT 第 91 页）：

• B = 1 时：传输门截止，反相器工作，F = ¬A；

• B = 0 时：传输门导通，F = A；

• 合起来 F = A·¬B + ¬A·B = A⊕B。

异或门的 CMOS 实现要 12 个管子，传输门只要 8 个左右——这就是为什么加法器（全加器核心是异或）大量使用传输门。

8.3 六条核心结论

① 静态互补 CMOS 的构造是机械的：大非号里画 PDN，对偶得 PUN，任何与/或表达式都能一步到位。

② 单级 CMOS 门必然反相；与/或要两级，所以设计偏爱反相逻辑。

③ 扇入是平方代价，扇出是线性代价；NAND 优于 NOR（因为 PMOS 弱）。

④ 尺寸规划：并联保持、串联加倍；宽门要拆级或插缓冲。

⑤ 有比逻辑省管子但费电；DCVSL 用差分+正反馈找回满摆幅。

⑥ 动态逻辑快但脆弱（漏电、电荷共享、级联约束）；传输门省管但有阈值损失，必须并联 PMOS 或加电平恢复。

9 自测题（含详解）

1. 用静态互补 CMOS 画出 Y = ¬(A·B + C·D) 的晶体管级电路，并说明 PDN 与 PUN 的结构。

2. 为什么 4 输入或非门比 4 输入与非门慢得多？

3. NAND3 的 NMOS 和 PMOS 各应取多宽（单位反相器 NMOS=1、PMOS=2）？输入电容是多少？

4. 伪 NMOS 反相器：VDD = 2.5 V，PDN 导通电阻 5 kΩ，负载 PMOS 等效电阻 50 kΩ。求 VOL。

5. 动态门 Out = ¬(A·B + C)，画出电路并说明预充/求值时的状态。

6. 为什么动态门不能直接级联？Domino 怎么解决？

7. NMOS 传输管传 1 时输出最高到多少？为什么？并说明传输门怎么解决。

参考答案

1. PDN：(A 串 B) 并 (C 串 D)；PUN：(A 并 B) 串 (C 并 D)。每个输入接一个 NMOS 和一个 PMOS，输出在中间，经反相得 Y。

2. NOR4 的 PDN 是 4 个 NMOS 并联（快），但 PUN 是 4 个 PMOS 串联；PMOS 迁移率只有 NMOS 的 1/3，再串联 4 个，电阻巨大，所以上升沿极慢。NAND4 的慢路径是 4 个 NMOS 串联，相对好得多。

3. NMOS 串联 3 个 → 各宽 3；PMOS 并联 3 个 → 各宽 2（保持单位尺寸）。输入电容 = (2 + 3) = 5 倍单位电容。

4. VOL = 2.5 × 5/(5+50) = 0.227 V。若要 VOL 更低，需加大 PDN 宽度（减小 R_PDN）。

5. Mp（PMOS，栅接 Clk）接 VDD，PDN = (A 串 B) 并 C，Me（NMOS，栅接 Clk）接地。Clk=0：Mp 通、Me 断，Out 预充到 1；Clk=1：Mp 断、Me 通，若 (A·B + C)=1 则 Out 放电到 0，否则保持 1。

6. 因为求值期前级输出可能“先预充到 1、再放电到 0”，而后级已经在同一时钟求值完毕，漏掉了这个跳变。Domino 在后级前加一个静态反相器，使每级输入只可能 0→1，保证单调性。

7. 最高到 Vgate − VTn。因为 Vout 升高使 VGS = Vgate − Vout 减小，当 Vout = Vgate − VTn 时 VGS = VTn，管子关断。传输门用 PMOS 并联解决：PMOS 传 1 没有阈值损失。
