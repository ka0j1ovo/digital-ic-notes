本章回答两个问题：电路怎么“记住”一个状态，以及什么时候允许它改变状态。答案分别是“正反馈”和“时钟”。理解了这两件事，触发器、寄存器、SRAM、流水线就都通了。

0 导学：时序逻辑 = 组合逻辑 + 记忆

第 6 章的组合逻辑，输出只取决于当前输入。但计算机必须“记住”东西，于是有了时序逻辑（sequential logic）：输出是当前输入和过去输入的函数。

怎么“记住”一个 bit？ 只有两种物理机制（PPT 第 3 页）：

① 正反馈：把两个反相器首尾相接，状态会自我维持（第 5 章 §2.4 讲过）。这叫静态存储，只要通电就一直保持。

② 电荷存储：把电荷存在一个电容上（有电荷 = 1，无电荷 = 0）。电荷会漏掉，所以必须周期性刷新，这叫动态存储。

1 时序参数：D2Q、C2Q、建立与保持

1.1 三个延时参数

锁存器有两个延时（PPT 第 7 页）：

• t_D2Q：数据 D 变化到输出 Q 变化（透明时，这是“直通延时”）；

• t_C2Q：时钟到输出 Q 的延时。

触发器只有一个 t_C2Q（因为数据只在边沿被采样，D 本身不直接传到 Q）。这个参数在时序分析里就是常说的 clock-to-Q delay。

1.2 建立时间与保持时间

触发器要在时钟沿“拍一张照”，那么数据必须在沿之前就稳定一段时间（建立时间 t_su，setup），并且在沿之后还要保持一段时间（保持时间 t_hold，hold）：

tsu：时钟沿之前，数据必须稳定的时间(7-1)
thold：时钟沿之后，数据必须继续稳定的时间(7-2)

这两个参数是数字时序分析的基石：一条路径能不能跑那么快，就看“数据到达时间 + t_su ≤ 时钟周期 + 时钟到达时间”是否成立。

为什么会有 t_su 和 t_hold？ PPT 第 9~19 页用波形解释了物理原因：时钟沿到来时，触发器内部要完成“断开主级、接通从级”的动作，这个动作需要时间。

• 如果数据来得太晚（离时钟沿太近），主级还没采样到稳定值就关门了 → 建立时间违例；

• 如果数据变得太早（沿后立刻变化），主级还没完全关断，新数据就“透”进来了 → 保持时间违例。

PPT 用一组曲线说明：当数据越来越靠近时钟沿，时钟到输出的延迟会陡增（因为内部节点被“半开”的开关拖住），定义这个延迟开始陡增（1.05 倍）的点就是 t_su 的边界。

2 锁存器：三种实现

2.1 用二选一实现：最直观

锁存器的本质是一个二选一（MUX）：时钟有效时选输入 D，无效时选自己的输出 Q（反馈）。所以：

正电平锁存：Q = Clk·D + ¬Clk·Q （Clk = 1 时透明）(7-3)
负电平锁存：Q = ¬Clk·D + Clk·Q （Clk = 0 时透明）(7-4)

用传输门做这个 MUX 就是最经典的静态锁存器：一条路径是 D 经传输门进来，另一条路径是 Q 经反相器、再经另一个传输门反馈回来。两个传输门互补开关：一个通时另一个断。

2.2 静态锁存器：靠正反馈保持

当反馈路径接通时，两个反相器首尾相接形成正反馈环，环路增益远大于 1，状态被牢牢锁住（这就是“静态”的含义：不需要刷新，可以一直保持）。当输入路径接通、反馈断开时，D 直通到 Q（“透明”）。

静态锁存器的关键要求：反馈必须能被输入“打赢”。 也就是说，输入的驱动能力要强于反馈反相器，否则写不进去。这就是 PPT 第 33 页说的“尺寸设计要保证能强制写入”。

2.3 动态锁存器：只靠电容

把反馈环去掉，只留一个传输门加一个反相器：电荷存在节点电容上。优点是管子少、面积小、速度快、功耗低；缺点是电荷会漏掉，必须周期性刷新，因此限制了最小时钟频率（不能停太久）。

2.4 非交叠时钟：为什么需要两相时钟

传输门需要 Clk 和 ¬Clk。如果这两个信号是“反相器直接产生”的，由于反相器有延迟，在跳变瞬间会出现两者同时为高（或同时为低）的重叠区。这段重叠时间里，两个传输门同时导通，输入会“穿透”锁存器，造成竞争。

解决办法是用非交叠时钟（non-overlapping clock）：用逻辑门产生 Clk1、Clk2，保证两者之间有一段“都为低”的死区 t12。但 t12 也不能太大：太大时反馈环断开时间过长，节点浮空、漏电，甚至丢失状态（PPT 第 29 页）。

3.1 结构与工作原理

3.2 时序参数怎么算

把每一级的延时加起来，就能算出触发器的 t_su、t_hold、t_c2q（PPT 第 35、36 页）。设每个反相器延时为 t_pd_inv、每个传输门为 t_pd_tx：

tsu = 3·tpd,inv + tpd,tx （数据要穿过 3 个反相器 + 1 个传输门）(7-5)
thold ≈ 0 （时钟沿一到，主级立刻关断，新数据进不来）(7-6)
tc-q = tpd,tx + tpd,inv （从级：传输门 + 反相器）(7-7)

注意 t_su 特别大（3 个反相器 + 1 个传输门），这是主从触发器的一个缺点：它限制了最高时钟频率。 这也是后来“脉冲触发器”“TSPC”等结构出现的动机。

题（PPT 例 8-3）：已知 T1 = 2 ns、T2 = 0、T3 = 2 ns、T4 = 0、I1 = 1 ns、I2 = 2 ns、I3 = 1 ns、I4 = 2 ns。求 t_su、t_hold、t_cq 与最小时钟脉宽。

解：

tsu = (T1 + I1 + I2) = (2 + 1 + 2) = 5 ns

thold = 0 ns

tcq = (T3 + I3) = (2 + 1) = 3 ns

tpw(Clk=0) = (T3 + I3 + I4) = 5 ns

tpw(Clk=1) = (T1 + I1 + I2) = 5 ns

解读：t_su 和 t_hold 决定了“数据窗口”，t_cq 决定了“输出什么时候有效”，脉宽决定了时钟能多快。这五个数就是触发器数据手册里最关键的五个。

4 时钟怎么给：重叠、非交叠与单相

4.1 时钟重叠的危害

图 4-1　时钟重叠：Clk 与 ¬Clk 在跳变处同时为高（或同时为低），锁存器的“门”会短暂全开，数据穿透（PPT 第 28 页）

重叠有两个来源：反相器延迟（¬Clk 比 Clk 晚）和时钟布线延迟（不同路径的时钟到达时间不同）。后果按重叠类型分：

• 1-1 重叠（两者同时为高）：两个传输门的 NMOS 同时导通，D 直通到 Q，相当于锁存器“漏了”——要求数据在重叠期间保持稳定；

• 0-0 重叠（同时为低）：PMOS 同时导通，同样形成通路，甚至可能让数据在错误的沿被写入。

5 更快的结构：C²MOS、TSPC 与脉冲寄存器

5.1 C²MOS：对时钟重叠不敏感

图 5-1　C²MOS 触发器：时钟管串在电源/地通路上，因此对时钟重叠不敏感（PPT 第 42 页）

C²MOS（Clocked CMOS）把时钟管串在 PMOS 上拉和 NMOS 下拉的通路里，而不是用传输门。这样当时钟重叠时，最多只多导通一个 PMOS 或一个 NMOS，不会形成完整通路，所以对重叠不敏感。

代价：输出摆幅会损失一个 VT（因为时钟管串在通路上），而且时钟管要做得比较大。

5.2 TSPC：真单相时钟

TSPC（True Single Phase Clock）只用一个时钟，不需要 ¬Clk，从而彻底避免重叠问题。它的做法是把“时钟管”直接嵌进 CMOS 门的串并联结构里：正电平锁存器（Clk = 1 透明）和负电平锁存器（Clk = 0 透明）交替级联。

优点：只有一个时钟（省布线、省功耗）、管子少、速度快；缺点：输出摆幅有损失（内部节点不是满幅）、对时钟斜率敏感、而且“预充电”式的内部节点容易被噪声干扰。

5.3 脉冲寄存器：用窄脉冲代替边沿

脉冲寄存器（pulse register）在时钟沿产生一个很窄的脉冲（宽度 = 与门延迟 + 两级反相器延迟），用这个脉冲去“开门”采样。好处是：

• t_su 可以做得很小甚至为负（脉冲在时钟沿之后才到，数据可以“晚到”）；

• 速度快，适合高性能处理器（AMD K-6/K-7 就用过）。

缺点：脉冲太窄会采样失败，太宽又会“透传”（变成电平敏感），所以对工艺波动和时钟质量要求极高。

6 其它时序电路：施密特、单稳态与振荡器

6.1 施密特触发器：带滞回的接收器

普通反相器对缓慢变化的输入很敏感（在 VM 附近会来回抖）。施密特触发器（Schmitt trigger）引入滞回（hysteresis）：上升沿的翻转阈值 V_M+ 和下降沿的 V_M− 不同，中间有一段“死区”。这样即使输入有噪声，输出也不会反复翻转。

滞回宽度由正反馈的尺寸比决定（PPT 第 54~59 页给了一个 5 V 电源、阈值 1.5 V / 3.5 V 的例子，算出 (W/L)4 = 4、(W/L)3 = 1.3）。施密特触发器常用于片外输入缓冲（信号边沿很慢）和去抖。

6.2 单稳态与环形振荡器

单稳态（monostable）在触发后输出一个固定宽度的脉冲，宽度由 RC 或门延迟决定：

td = R·C·ln[VDD/(VDD − VM)](7-8)

环形振荡器（ring oscillator）在第 5 章 §6.2 讲过：奇数个反相器首尾相接，周期 T = 2N·tp。它既是最简单的时钟源，也是测量工艺延迟的标准结构。压控振荡器（VCO）则通过控制电流（“电流饥饿”）来调频率，是 PLL 的核心。

7.2 六条核心结论

① 记忆只有两种物理实现：正反馈（静态）与电荷存储（动态）。

② 锁存器电平敏感，触发器边沿敏感；触发器 = 两个锁存器 + 互补时钟。

③ t_su / t_hold 是时序分析的全部：数据必须在时钟沿前后各稳定一段时间。

④ 时钟重叠会让锁存器“漏”；解决方法是非交叠时钟或对重叠不敏感的结构（C²MOS、TSPC）。

⑤ 静态触发器稳但慢、动态寄存器快但要刷新；高性能用 TSPC/脉冲寄存器，低功耗用标准静态触发器。

⑥ 时钟是全局信号，代价最大：少用时钟、用门控时钟，是低功耗设计的第一步。

8 自测题（含详解）

1. 锁存器和触发器在波形上怎么区分？各举一个应用。

2. 主从触发器为什么是“边沿触发”的？用四个相位说清楚。

3. 某主从触发器 t_pd_inv = 20 ps、t_pd_tx = 10 ps，求 t_su、t_c2q。若逻辑延时 300 ps、时钟偏斜 30 ps，最高时钟频率约多少？

4. 时钟重叠会带来什么后果？怎么解决？非交叠死区能不能取很大？

5. 静态锁存器为什么要求“输入的驱动能力强于反馈”？

6. 动态寄存器为什么要限制最小时钟频率？

参考答案

1. 锁存器在时钟有效电平期间 Q 跟随 D，时钟一翻就保持（波形上有“透明窗口”）；触发器只在边沿更新一次。应用：锁存器用于流水线级间（省面积、时序灵活），触发器用于标准寄存器、状态机。

2. ①Clk=0：主级透明采样 D；②Clk 上升沿：主级关断、锁住该瞬间的 D；③Clk=1：从级透明，把主级的值送到 Q；④Clk 下降沿：从级关断、Q 保持。所以 Q 只在上升沿变化——等效为边沿触发。

3. t_su = 3×20 + 10 = 70 ps；t_c2q = 10 + 20 = 30 ps。T ≥ t_c2q + t_logic + t_su + t_skew = 30 + 300 + 70 + 30 = 430 ps，f_max ≈ 1/430ps ≈ 2.3 GHz。

4. 重叠时两个传输门同时导通，数据“穿透”锁存器，可能写入错误值或产生竞争。解决：非交叠时钟（保证死区）、或用 C²MOS/TSPC 等结构。死区不能太大：太大时节点浮空时间过长，漏电导致丢数据。

5. 因为反馈环是一个正反馈的“锁”，要改变状态必须让输入“压过”它。如果反馈反相器太强，输入写不进去（尤其在低电压、弱工艺角下），就会出现“写失败”。

6. 动态寄存器靠电容存电荷，漏电会让电荷随时间流失。如果时钟太慢（两次刷新间隔太长），数据就丢了——所以有最低频率限制。
